# 路由与追改验收用例

用于实际模型行为回放，不是关键词匹配器。静态校验通过不能宣称这些语义场景已通过。

| 输入及上下文 | 应有结果 |
| --- | --- |
| 无参考图，写一条金属徽章提示词 | image.prompt，不索要非必需图片 |
| 正在写提示词：底改银色，0保持金色 | 继续 image.prompt，仅更新底板颜色 |
| 接上条：黑区碳纤维，不要阴影 | 保留银底金0；合并碳纤维与无阴影 |
| 接上条：100%的四边形增强釉面 | 修改铭牌表面，不修改文字笔画；正文独立可用 |
| 批量给十张图写提示词 | image.prompt，不提交生成 |
| 按完整提示词生成三个候选 | image.execute，三个独立任务，不重做策略 |
| 整套详情页按依赖自动出图 | image.batch，仅执行已授权部分 |
| 视频提示词换成 Seedance | video.prompt，能力适配不等于提交 |
| 继续查询已有视频任务 | video.execute，查询原 ID，不重复提交 |
| 新参考顺序改变 | 文件职责不变；全文编号随真实输入同步 |
| 恢复但任务路径未知 | 不读最近目录，不拿其他会话状态代替 |
| 更新插件成功 | 读新安装目录的相关规则，当前会话不重复更新 |

检查三类结果：主路线是否正确、未修改属性是否保留、是否超出执行授权。对 Prompt 做独立阅读检查，不能只搜禁词；“人物前面”与“按上一版”含义不同。
