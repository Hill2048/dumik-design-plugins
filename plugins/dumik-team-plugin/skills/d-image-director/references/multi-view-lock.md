# 多视角结构资料库与 Logo 策略

解决「每张角度都像另一款产品」。成套主图/详情前先建**结构资料库**，再写单张 Prompt。

## 结构资料库（每产品一份）

| 字段 | 内容 | 来源 |
| --- | --- | --- |
| 标准角度表 | 正 3/4、顶视、侧视、细节特写等本系列要用的机位 | 白底/实拍 |
| 轮廓锚点 | 各角度下最稳的剪影特征 | 观察记录 |
| 部件地图 | 把手、接口、按键在各视角的可见性 | 不可瞎补被遮挡面 |
| 固有色与材质 | 各表面名称与颜色家族 | 控制层 P0 |
| Logo 策略 | 见下 | 设计确认 |

资料库可写在项目 `design.md` 或任务笔记；写 Prompt 时引用，不每次重发明。

## 多视角写词规则

1. **同一结构真源**：所有角度优先同一套白底/设定图；换角度是相机动，不是产品改款。
2. **不可见面标无法确认**：侧视看不见的背面接口 → 不编造；需要背面另供参考图。
3. **系列镜头气质继承**：俯仰范围、景别松紧跟系列规则表，单张只调裁切。
4. **细节特写仍锁比例**：局部放大不得拉长部件相对关系。

## Logo / 丝印策略

| 策略 | 何时用 | Prompt 写法 |
| --- | --- | --- |
| A. 占位锁定 | 生成图只要位置对，字可后期叠 | `Logo 区保留占位与比例，不要求可读字形` |
| B. 清晰可读 | 用户明确要求生成即出字且有清晰参考 | 提供清晰 Logo 参考图；禁止模型自由发挥字体 |
| C. 后期叠加（推荐电商） | 主视觉先过结构验收 | 生成阶段禁止乱字；成品在 PS/模板叠正式 Logo |

默认推荐 **C 或 A**，避免模型乱码字导致整图作废。

## 资料库最小模板

```markdown
## 结构资料库｜<产品名>
- 标准角度：…
- 轮廓锚点：…
- 部件地图：…
- 固有色：…
- Logo：占位锁定 / 后期叠加（选一）
- 禁止机位：极端广角、无意义仰视…
```

## 自检

- [ ] 新角度是否仍指向同一结构真源
- [ ] Logo 是占位、可读还是后期，三者是否写清
- [ ] 被遮挡部件是否标了无法确认


## 角度切换检查

换角度前三问：

1. 新角度的结构真源图是否存在？  
2. 新角度下哪些部件变为不可见？  
3. Logo 策略是否仍成立（侧视可能看不见正面丝印）？

任一答不上来 → 先补资料库，不硬写 Prompt。

## 产品身份卡（16:9 四视图定妆照）

- **适用场景**：只有单张/少数参考图但后续要跨多屏切视角、或需要把复杂主体先提取为标准白底设定集时，先出一张 16:9 四栏定妆照锁死结构与比例。
- **四栏结构逻辑**：
  1. 第 1 栏：**识别度大特写**（锁死核心材质肌理、品牌标志/铭牌、接口或最难保真的局部工艺）；
  2. 第 2 栏：**正面全身**；
  3. 第 3 栏：**左侧面全身**；
  4. 第 4 栏：**背面全身**。

```text
提取 @图1 中的[目标产品，如棕色盘子/纯钛马克杯]

16:9 画幅，4K 超高清，产品写实摄影，纯白背景，专业产品棚拍，产品四视图定妆照，从左到右依次：识别度大特写、正面全身、左侧面全身、背面全身，同一产品，比例完全统一。
```
