# 多视角结构资料库与 Logo 策略

解决「每张角度都像另一款产品」。成套主图/详情前先建**结构资料库**，再写单张 Prompt。

## 结构资料库（每产品一份）

| 字段 | 内容 | 来源 |
| --- | --- | --- |
| 标准角度表 | 正 3/4、顶视、侧视、细节特写等本系列要用的机位 | 白底/实拍 |
| 轮廓锚点 | 各角度下最稳的剪影特征 | 观察记录 |
| 部件地图 | 把手、接口、按键在各视角的可见性 | 不可瞎补被遮挡面 |
| 固有色与材质 | 各表面名称与颜色家族 | 控制层 P0 |
| Logo 策略 | 见下 | 设计确认 |

资料库可写在项目 `design.md` 或任务笔记；写 Prompt 时引用，不每次重发明。

## 多视角写词规则

1. **同一结构真源**：所有角度优先同一套白底/设定图；换角度是相机动，不是产品改款。
2. **不可见面标无法确认**：侧视看不见的背面接口 → 不编造；需要背面另供参考图。
3. **系列镜头气质继承**：俯仰范围、景别松紧跟系列规则表，单张只调裁切。
4. **细节特写仍锁比例**：局部放大不得拉长部件相对关系。

## Logo / 丝印策略

| 策略 | 何时用 | Prompt 写法 |
| --- | --- | --- |
| A. 占位锁定 | 生成图只要位置对，字可后期叠 | `Logo 区保留占位与比例，不要求可读字形` |
| B. 清晰可读 | 用户明确要求生成即出字且有清晰参考 | 提供清晰 Logo 参考图；禁止模型自由发挥字体 |
| C. 后期叠加（推荐电商） | 主视觉先过结构验收 | 生成阶段禁止乱字；成品在 PS/模板叠正式 Logo |

默认推荐 **C 或 A**，避免模型乱码字导致整图作废。

## 资料库最小模板

```markdown
## 结构资料库｜<产品名>
- 标准角度：…
- 轮廓锚点：…
- 部件地图：…
- 固有色：…
- Logo：占位锁定 / 后期叠加（选一）
- 禁止机位：极端广角、无意义仰视…
```

## 自检

- [ ] 新角度是否仍指向同一结构真源
- [ ] Logo 是占位、可读还是后期，三者是否写清
- [ ] 被遮挡部件是否标了无法确认


## 角度切换检查

换角度前三问：

1. 新角度的结构真源图是否存在？  
2. 新角度下哪些部件变为不可见？  
3. Logo 策略是否仍成立（侧视可能看不见正面丝印）？

任一答不上来 → 先补资料库，不硬写 Prompt。

## 产品身份卡（16:9 四视图定妆照）

- **适用场景**：只有单张/少数参考图但后续要跨多屏切视角、或需要把复杂主体先提取为标准白底设定集时，先出一张 16:9 四栏定妆照锁死结构与比例。
- **四栏结构逻辑**：
  1. 第 1 栏：**识别度大特写**（锁死核心材质肌理、品牌标志/铭牌、接口或最难保真的局部工艺）；
  2. 第 2 栏：**正面全身**；
  3. 第 3 栏：**左侧面全身**；
  4. 第 4 栏：**背面全身**。

```text
提取 @图1 中的[目标产品，如棕色盘子/纯钛马克杯]

16:9 画幅，2K 超高清，产品写实摄影，纯白背景，专业产品棚拍，产品四视图定妆照，从左到右依次：识别度大特写、正面全身、左侧面全身、背面全身，同一产品，比例完全统一。
```

## 场景身份卡（16:9 世界观总设定照）

- **适用场景**：当详情页有多张场景屏需明确落在「同一间房子、同一套家具与人物关系」中、避免每屏各自发挥像换了几个房间时，先生成一张 `16:9` 2K **场景身份卡**作为全案空间真源。
- **两区黄金布局（参照人物身份卡，左特写 + 右人景合一全景）**：
  1. **左区（约左 2/5）· 放品落位桌面大特写**：微俯聚焦未来真正摆产品的桌面核心区（空净台面 + 托盘/杯垫 + 附近材质边角 + 晨光落点），桌面**严禁抢先放产品**；
  2. **右区（约右 3/5）· 亲密尺度的完整人景大全景**：收拢聚拢的生活空间（不空旷大空厅），完整交代光向、墙地材质与高定设计师家具尺度（如单人沙发紧挨设计师小圆几），并可把已锁定的**主角模特自然置于其中（空手不持产品）**。
- **只锁世界观，不拴死机位（反展厅目录式全框）**：下游单屏引用场景身份卡时，仅锁定「同一个房间、家具材质、配饰与光向」，**绝不能每张都像展厅一样退远把整张沙发和整张圆桌全塞进画框**；必须大胆用**斜切裁边（只露半个灯罩或一角沙发皮缘）、贴桌面 3cm 低角度微仰、90° 上帝视角几何平面、局部时装裁切与前虚后实景深**拉出大牌杂志冲击力。
- **反串联垫图红化铁律**：调试场景身份卡或后续各屏出图时，**严禁拿已经生成出来的候选图反复串联垫图重绘**（每次叠加垫图都会不断累积偏红/偏品红/发闷色偏）；需要调整家具、视角或细节时，一律回到**原始干净基准图**修改提示词重新直出。

```text
比例：16:9

@图1：[视觉风格/光学母版，严禁带入原图产品]。@图2：[人物身份卡，仅锁最左侧清晰五官与穿搭，忽略小图脸部红块]（可选）。

制作一张 16:9 2K 超高清杂志级「场景身份卡（世界观总设定照）」，左右两区组合，全画幅所有桌面与人手均保持空净无目标产品：
- 左区（约左 2/5）：微俯 35° 聚焦未来摆放产品的桌面核心落位区大特写——展示平整连续的桌面材质、空置托盘/杯垫与周围配套配件质感，主光自然打在空落位区上；
- 右区（约右 3/5）：尺度亲密聚拢的室内完整生活角大全景（拒绝空旷大空厅）——完整交代窗光、墙地材质与高定设计师家具比例（如单人沙发紧挨设计师小圆几），将 @图2 同一模特空手自然置于其中（微表情与视线落点清澈自然）。

约束：两区色彩清透准确、严禁偏红发闷；桌面与人手必须空净无目标产品；严禁出现红块、木纹/大理石等禁材或任何文字。
```

## 摆件身份卡（实物目录选样卡 & 单品锁定卡）

> **100 张 Pinterest 静奢摆件实拍审美 DNA**（折边金属托盘、手造微瑕粗陶、雕塑单枝花器、柔雾台灯、皮具文具编排与斜切窗影法则）详见同目录 [pinterest-100-props-dna.md](pinterest-100-props-dna.md)，设计摆件库与选样卡前必读。

- **适用场景**：全案高频复用的关键配角道具（餐盘小碟、陶瓷/真皮托盘、香插、花器、蘑菇台灯、雕塑边几等），先用「实物目录选样」筛出完全符合项目调性与禁材红线的单品，再裁切或扩成单品身份卡入库 `设定集/场景身份卡/`（或 `设定集/摆件身份卡/`），根治下游各屏配角画风乱跳、花哨抢戏或塑料感。
- **六大底层机制（提炼自高端器物目录实拍法）**：
  1. **体裁锚定「实物目录摄影 / 工艺图录」**：用 `高端器物实物目录摄影 / 工艺选款实拍样片` 替代普通静物场景词，天然屏蔽桌布褶皱、食物碎屑、餐巾刀叉等杂物干扰。
  2. **浅暖灰纯净底（优于 `#FFFFFF` 死白底）**：米白瓷、骨瓷、透明玻璃、银色金属等浅色/透光摆件在纯死白底上极易吞边缘、丢高光与透光厚度；统一用 `浅暖灰纯净平滑台面`，既托出干净外轮廓与轻盈接触投影，下游垫图时又零杂色污染。
  3. **微倾准俯视 + 侧上方掠射柔光**：机位用 `几乎正俯拍并略微倾斜（75°–85°）` 兼顾平面廓形与口沿高度；光线必写 `侧上方柔和定向光 / 掠射日光`，靠微高光与阴影勾出同色浅浮雕、薄唇倒角、哑亮釉交界与玻璃折面，禁平光拍扁。
  4. **物理光学拆解替代空洞形容词**：
     - 同色浮雕：写明方向与凹凸形态 + `同色立体起伏靠微高光阴影呈现，不是彩绘线条、不是异色印花`；
     - 复合光泽：写明分区过渡（如 `外沿窄圈哑光收口，内盘细腻半亮釉自然过渡`）；
     - 透光玻璃/亚克力：写明厚薄凝色（如 `器身平处近乎无色通透，仅在薄边与叠厚转折处凝出淡烟茶色，细小干净高光呈现真实厚度`）。
  5. **配角克制与承载区净空铁律**：承载面（盘心/托盘面/桌面）必须写死 `大片净空平整、无食物无杂物`，供下游自由叠放主产品或半块茶点；若带彩釉/手绘线饰，必须锁死 `仅限外沿或局部 ≤1/3 延展、中心留白`，严禁满铺花纹或金边抢走主产品视觉中心。
  6. **阵列防粘连硬锁**：多款并排必写 `独立完整、等距互不接触、留出裁切间距、外缘完整入镜不裁切、无分格线无文字编号`，方便选定后直接单格无损裁切入库。
- **四种选样控制变量法（按项目阶段选用）**：
  - **同色微肌理梯度（1×3 横排）**：锁死同色同材质同外轮廓，只让外沿浮雕/拉丝/锤纹按「窄密 → 适中匀称 → 稍宽圆润」拉出三级微差（适合定调高定白瓷、纯色石器、金属托盘）。
  - **跨材质与薄厚比例对比（1×3 横排）**：同极简无纹基调下，横向对比「哑亮过渡细瓷 vs 微抬薄片圆角方器 vs 叠厚凝色透光玻璃」，靠廓形与材料光学定调。
  - **克制局部线饰/撞色边选样（1×3 横排）**：对比「外缘 1/3 手绘细枝 vs 极窄撞色釉唇 vs 放射切割折面」，在克制前提下挑一抹点睛色。
  - **多维器型×色釉矩阵（3×2 六宫格）**：按 `左上 / 中上 / 右上 / 左下 / 中下 / 右下` 坐标一次性铺开不同器型（圆/椭圆/带耳）与低饱和色系，适合前期快速海选配角方向。

### 模板 A：1×3 摆件精研选样目录卡（扁平/浅腔器物选定后可直接单件裁切做身份卡）

```text
比例：16:9

精致高端[器物品类，如现代餐盘/桌面托盘/香插小碟]实物目录摄影。横向单排并列展示三件独立完整的空置[器物]，从左至右等距排列，尺寸相近，彼此互不接触，外侧各留足空白，边缘全部完整入镜不裁切：
- 左：[款式1：廓形 + 固有色与材质 + 边缘薄厚/光泽分区/微肌理，如温暖米白细瓷正圆浅盘，外圈窄沿带沿半径排列的细密竖条同色浅浮雕棱纹，靠微高光阴影呈现而非彩绘线条，盘心宽阔平滑半亮釉]；
- 中：[款式2：只改单一工艺梯度或跨材质对比，如暖象牙圆角方盘，四边轻微上抬、四角连续圆润，极薄瓷唇无刻纹，温润半哑光泽如轻托薄瓷片]；
- 右：[款式3：第三梯度或透光/金属对比，如浅烟茶色通透玻璃正圆浅盘，宽弧沿光滑无纹，盘心近无色，仅在薄边与叠厚转折处凝出淡茶色，细小干净高光表现真实玻璃厚度]。

几乎正俯拍并略微倾斜以看清边缘厚度与起伏，统一置于浅暖灰纯净平滑台面，大片留白；侧上方柔和掠射定向光，清晰勾勒边缘转折、浮雕起伏与细腻釉面/玻璃反射，轻盈真实的接触阴影。简约高级品牌产品选样实拍，器物内部干净空置。

约束：无食物、无餐巾杂物、无金边、无满铺花纹、无拼接分格线、无任何文字或数字编号。
```

> 若需前期海选 6 款，将首句排布改为「`六件独立空置[器物]分为三列两行均匀排布，各自独立留有裁切间距`」，并按 `左上 / 中上 / 右上 / 左下 / 中下 / 右下` 逐格写清器型与局部色边即可。

### 模板 B：三维立体摆件单品锁定身份卡（台灯 / 雕塑边几 / 咖啡器具等立面复杂配角）

当摆件高度较高、单靠俯拍看不清立面比例与底座收口（如蘑菇台灯、雕塑小茶几、手冲壶）时，选定款式后出一张 `16:9` 三栏单品身份卡锁死三维结构：

```text
比例：16:9

提取 @图1 中选定的[目标摆件，如拉丝银蘑菇台灯/深咖哑光陶瓷高足果盘]，制作一张 16:9 2K 超高清高端家居品牌实物目录身份卡，浅暖灰纯净无缝摄影棚背景，从左至右横向三栏独立排布，互不遮挡且比例完全统一：
- 左栏：关键工艺与收口微距特写（清晰锁定[顶部浅碟凹与极扁一字顶钉 / 边缘倒角与材质拉丝纹理]）；
- 中栏：正面平视全身图（完整展示高度比例、立柱粗细与宽倒角底座接触关系）；
- 右栏：微俯 35° 斜侧 3/4 全貌图（展示立体体量、弧面环境漫反射与轻盈接触投影）。

侧上方柔和定向棚光配合干净轮廓反光，真实呈现[拉丝冷银金属 / 哑光粗陶 / 焦糖粒面真皮]表面光学层次，三栏同一器物、固有色与几何结构严丝合缝。

约束：无多余家具杂物、无木纹与大理石禁材、无分格黑线、无文字标尺或编号。
```
