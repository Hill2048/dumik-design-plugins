# 图片提示词合同

这是当前图片提示词的交付检查；比例判断、写词方法和模式细节见 [详细写词规范](legacy/D-image-prompt.md)，材质和人物方法按需读 `templates.md`。不要只看本摘要而跳过适用规则。最终交付必须满足：

- 首行只写比例；最终可复制提示词放在代码块内，代码块首行重复同一比例。
- 多图使用 `@图1`、`@图2` 等，并按实际输入顺序写角色职责；角色说明只出现一次。单图不强加角色行。
- 主指令直接写最终画面，不用“在上一版基础上”“沿用之前”“其他不变”等省略有效内容。具体空间描述（人物前面）和明确输入关系（沿用@图1构图）不属于聊天依赖，不按词机械禁止。
- 追改保留当前任务已经确认的决定，只并入本轮变化。新参考图先判断补充、替换或新目标，不静默改变旧职责。
- `@图N` 是图片输入标签，不是模型名、API 字段、命令参数、变量名或文件名；这些技术名称保持原样。
- 约束只在末尾集中写与当前画面真实相关的风险，不用通用负面清单代替画面描述。
- **提示词瘦身红线与去噪规范（发包前必查）**：
  - **字数上限**：单张主图 / 详情分屏 / 改图控制在 **180 ~ 380 字**（硬上限 **450 字**）；2×2 四宫格抽卡控制在 **350 ~ 550 字**（共用视觉设定只在开头写 1 遍，4 个分格每格只写 **1 句 20 ~ 35 字构图差异**，严禁每格重复抄材质与铭牌清单）。
  - **去 Markdown 噪音**：最终发给生图模型的正文**严禁使用 `**加粗**`、`【】` 工程小标题、多级编号列表和括号套括号**，统一写成 3 ~ 4 段流畅自然的中文视觉短段；不混入 `100% 绝对真源`、`控制区/自由区` 等内部工程黑话。
  - **负面精简与替换式追改**：负面约束只在文末写 **1 句短句（≤5 个真实风险词）**，严禁在正文中穿插括号罗列长负面词（防止模型反向激活画出禁物）；追改必须**直接删掉旧错词并替换成正向描写**，禁止往旧词后不断叠加补丁导致长度滚雪球。
  - **垫图做减法**：已垫 `@图1` 白底图或 `@图2` 已定稿概念母版时，只写「保持什么 / 延续什么 / 本屏唯一变化点」，不把参考图里一眼可见的细节再复述两三百字。
- **纯无字底图与后期留白**（项目制电商出图）：除产品本体实拍上真实存在的原生丝印/激光刻字按 `@图N` 原样保留外，严禁在提示词中要求生成任何标题字、卖点文案、数字标尺、指示引线、放大圆框、价格贴纸或角标；按画面用途预留 `25%~35%` 干净低反差负空间给后期人工 PS 排版，并在禁止段写明禁止排版文字与标尺图标。
- **单图文件就地覆盖**：在项目内编写或追改具体编号画面时，把最新生效的完整提示词与 `@图N` 文件绑定直接覆盖写入 `制作/<编号_名称>/prompt.md`（不留 `v1/v2` 旧稿）。

最终自检：移除聊天历史后，仍能确定改谁、改什么、每张图负责什么、哪些内容保持、是否实际生成。

追改先将本轮要求绑定到具体部件，再更新属性；不将承载文字的铭牌误认成字的笔画。合并有效状态后重写最终正文，不直接把用户的“继续改”句子粘入模型请求。
