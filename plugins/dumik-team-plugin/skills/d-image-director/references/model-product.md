# 模特与产品同框

在 `templates.md` 人像保真之外，电商强制三点：**佩戴/持握关系、同源光、信息量克制**。

## 佩戴 / 持握关系

| 关系 | 必须写清 |
| --- | --- |
| 手持 | 哪只手、握点、手指压力与遮挡是否挡住卖点 |
| 佩戴 | 表带/眼镜/饰品如何贴合；皮肤接触与缝隙 |
| 摆放身前 | 距离身体、是否遮挡服装关键结构 |
| 试用态 | 锅铲入锅、筷夹取等动作，不改产品外形 |

产品比例以产品参考图为准，不得为「更好看的手势」拉大缩小产品。

## 同源光

人与产品必须像同一盏灯下：

- 主光方向对人脸与对产品一致。
- 接触阴影：手指–产品、产品–台面同一套软硬。
- 禁止：人脸棚拍光 + 产品另一套 HDR 环境光「拼贴感」。

## 信息量克制

- 一张图一个主信息：显脸 **或** 显产品工艺，不要又换脸又换场景又加三件道具。
- 背景道具最多服务叙事一句；自由区不得抢产品与手部关系。
- 文字/Logo：人脸图更易乱字 — 优先后期叠 Logo（见 `multi-view-lock.md`）。

## 最小模板

```text
@图1：模特身份与姿态真源。@图2：产品结构真源。

以 @图1 锁定人物身份与姿态；以 @图2 锁定产品结构与固有色。
产品[手持/佩戴方式]，手指压力与接触阴影自然；人与产品受同一[主光描述]。
信息量克制：不新增第二主产品；背景仅[一句]。
禁止：换脸；产品变形；乱字；光方向分裂；多手指。
```

## 与 templates 人像段

身份锁、皮肤、换脸禁令以 `templates.md` 为准；本文件只加电商产品同框的三点。两者冲突时：**不换脸 + 产品 P0** 优先于氛围修饰。
