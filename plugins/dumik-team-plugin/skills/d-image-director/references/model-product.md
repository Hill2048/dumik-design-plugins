# 模特与产品同框

在 `templates.md` 人像保真之外，电商强制三点：**佩戴/持握关系、同源光、信息量克制**。

## 佩戴 / 持握关系

| 关系 | 必须写清 |
| --- | --- |
| 手持 | 哪只手、握点、手指压力与遮挡是否挡住卖点 |
| 佩戴 | 表带/眼镜/饰品如何贴合；皮肤接触与缝隙 |
| 摆放身前 | 距离身体、是否遮挡服装关键结构 |
| 试用态 | 锅铲入锅、筷夹取等动作，不改产品外形 |

产品比例以产品参考图为准，不得为「更好看的手势」拉大缩小产品。

## 同源光

人与产品必须像同一盏灯下：

- 主光方向对人脸与对产品一致。
- 接触阴影：手指–产品、产品–台面同一套软硬。
- 禁止：人脸棚拍光 + 产品另一套 HDR 环境光「拼贴感」。

## 信息量克制

- 一张图一个主信息：显脸 **或** 显产品工艺，不要又换脸又换场景又加三件道具。
- 背景道具最多服务叙事一句；自由区不得抢产品与手部关系。
- 文字/Logo：人脸图更易乱字 — 优先后期叠 Logo（见 `multi-view-lock.md`）。

## 最小模板

```text
@图1：模特身份与姿态真源。@图2：产品结构真源。

以 @图1 锁定人物身份与姿态；以 @图2 锁定产品结构与固有色。
产品[手持/佩戴方式]，手指压力与接触阴影自然；人与产品受同一[主光描述]。
信息量克制：不新增第二主产品；背景仅[一句]。
禁止：换脸；产品变形；乱字；光方向分裂；多手指。
```

## 与 templates 人像段

身份锁、皮肤、换脸禁令以 `templates.md` 为准；本文件只加电商产品同框的三点。两者冲突时：**不换脸 + 产品 P0** 优先于氛围修饰。
- 多屏/多场景复用同一模特或同一双持握人手时，优先用 `templates.md` 中的「人物身份卡」或「手模四视图」先提取纯白底标准设定图，再进入同框/持握成片，避免每屏手型、美甲或五官漂移。

## 人物生命感与画面故事感（反证件照摆拍）

- **表情与视线必须经过设计（严禁无神面无表情）**：人物面部/头部入画时，必须把**微表情与精确视线落点**当作硬导演项写进正文——拒绝呆滞发空；**哪怕采用高级冷淡/疏离感，也必须是设计过的“清冷笃定”（如微抬下颌 3°、视线定定越过窗边晨光或沉静落于杯面热雾、眉眼放松带克制呼吸感或唇角一丝若隐若现松弛感）**，而不是无目的死盯。常见三态：① 低眸专注享受热饮热气；② 侧眸望向窗外光束的清冷杂志感；③ 刚翻完书页微抬头转向器物的柔和松弛瞬间。
- **拒绝“端杯站桩与展厅全框”**：禁止正对白墙僵硬举杯或总把整张沙发圆桌框死；多用大牌杂志局部裁切（如鼻尖唇线以下到腰线的半身时装特写、前虚化书页/灯罩偷拍景深、隔桌取杯微倾斜动作）。
- **肢体与衣摆呼吸感**：手部持轻巧器皿时写成「拇指与两指自然松弛捏勾把手、其余手指微屈」，禁止攥死握拳；结合发丝微动、真丝衣带/袖口自然垂折与身体靠倚重心，让画面像抓拍下的一帧真实生活片段。
- **道具链讲清前因后果**：前景可极克制虚化书页、眼镜或刚放下的小奶壶/手冲壶，交代“刚才发生了什么”，让静物与人共同讲一个小故事（仍严禁抢走主产品焦点）。
