# 六段结构（+产品锁 + 负面）

用于从零写或教学式展开一条完整提示词。电商改图可把六段压进 `prompt-contract` 的一段主指令，但检查时仍按六段过一遍。

## 六段定义

| 段 | 名称 | 电商落地写法 |
| --- | --- | --- |
| 1 | 主体 | 产品品类 + 可见形态；有图时写「以 @图N 为结构真源」 |
| 2 | 风格 | 摄影语言/品牌调性（须来自 design.md 或用户确认） |
| 3 | 光影 | 调性×反差、主光、接触阴影（见 `lighting-control.md`） |
| 4 | 构图 | 机位、占比、留白、与卖点区关系（见 `camera-language.md`） |
| 5 | 媒介 | 如：商业产品摄影、棚拍、自然窗光纪实 — 选一，勿堆 |
| 6 | 参数 | 画幅比例、景深意图、清晰主体；不当真「焦距 mm」迷信，当视觉语言 |

## 强制附加两段（电商）

| 附加 | 作用 |
| --- | --- |
| 产品锁 | 比例、部件、接口、固有色、Logo 占位 — 来自控制层 P0 |
| 负面 | 本任务禁止项，单独成段 |

缺产品锁的「漂亮六段」对电商主图不合格。

## 填空示例（锅具主图）

```text
主体：纯钛炒锅，以 @图1 锁定外轮廓、锅耳、盖钮与钛金属固有色。
风格：冷静专业的厨电电商摄影（继承 design 设计语言）。
光影：侧上柔光，光比收窄；台面接触阴影保留；锅内壁有柔和环境反射。
构图：微俯 3/4，主体约占画幅 55%，底部留台面边缘。
媒介：商业产品摄影，干净台面，无人物。
参数：比例 2:3；主体锐利，背景轻微分层虚化，忌夸张广角畸变。
产品锁：不改变锅耳形状与数量；Logo 区仅占位，不编造可读字。
禁止：乱码字、水印、第二口锅、把手变形。
```

## 使用规则

1. 有参考图时：段 1 必须绑定 `@图N` 职责，不要只靠文字重述外形。
2. 白底转场景：先完成产品锁与接触关系，再扩段 2–4 的场景层（`white-to-scene.md`）。
3. 与 `prompt-segments.md` 冲突时：**控制优先级**听分段顺序里的主体锁；**叙述排版**可听六段。
4. 不要把段 6 写成伪 EXIF 堆砌（ISO/快门一长串）而无清晰/虚化意图。

## 自检

- [ ] 六段是否都能指出可见结果
- [ ] 产品锁与负面是否独立存在
- [ ] 风格段是否引用了已确认设计语言（否则标待确认）


## 压缩交付

对熟悉流程的执行者，六段可压成一段主指令，但自检仍按六段+产品锁+负面勾选；漏产品锁即不合格。
