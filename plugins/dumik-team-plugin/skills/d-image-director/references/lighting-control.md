# 光影控制

把「高级光、电影感、通透」落成可执行的光关系。细节与材质反射可与五维编译、templates 材质段配合。

## 调性 × 反差

先选二维，再写光源：

| 调性（例） | 反差（例） | 可见结果 |
| --- | --- | --- |
| 冷静专业 | 低–中 | 光比收窄，暗部有细节，不闷黑 |
| 暖家常 | 中 | 窗光或侧柔光，阴影边缘软 |
| 戏剧强调 | 高 | 明确主光方向，受光/背光分界清晰，仍保留材质信息 |

禁止只写调性形容词；必须带**主光方向 + 软硬 + 光比意图**。

## 必写三项

1. **主光**：位置（侧上/顶/窗左）、软硬（柔光箱/硬光）、是否有辅光或反光板。
2. **接触阴影**：产品与台面/道具接触处的窄阴影；去掉则易假。
3. **材质反射差**：金属宽高光 vs 塑料钝高光 vs 木材纤维漫反射 — 同场景光源下表现应不同。

## 阴天 / 「更暗」「更通透」翻译

| 用户说法 | 落地写法 |
| --- | --- |
| 阴天 | 均匀漫射、收窄光比、提亮暗部、软化投影、保留暗部细节 |
| 更暗 | 降环境或缩小受光面；**不要**压成死黑块、抽干固有色 |
| 更通透 | 控制高光形状与空气感/轻微雾，同时保住边缘与材质层次 |
| 电影感 | 明确主光方向 + 受控光比 + 背景分层；不靠橙青滤镜词 |

## 真实摄影 + C4D / 3D 分工声明

混合参考时写清职责，禁止「又真又 CG 又高级」万能词：

```text
@图1：实拍产品，锁结构与固有色。
@图2：C4D/三维参考，只借布光与台面反射逻辑，不借重拓扑外形。
```

- 实拍负责：身份、磨损逻辑、真实反射噪声。
- 三维负责：可控布光、干净台面、可重复机位。
- 冲突时：**结构听实拍，光可听三维**，并在 Prompt 写明。

## 薄透斜阳 × 镜面金属高反差解法

当画面既要保留**温暖奶白「薄薄阳光感」**，又要让**抛光不锈钢/亮面金属不发灰**时：

- **主光写薄透百叶漫射**：写明“隔半透白色百叶窗滤入的上午低反差漫射暖阳，亮区为温暖象牙奶白带极淡百叶柔影，暗部为透气暖浅灰而非死黑”。
- **镜面反光借中段虚焦重色，禁画硬黑条**：不要在墙面硬切深黑横条；改在画面**中段靠右后安排自然景深虚化的深暖炭咖空间影区**（如虚焦椅背、建筑折角或暗色壁龛），必要时在器物背侧透出聚拢柔散的暖橙光学光晕，与上方百叶亮白交错，在抛光金属表面自然映出脆亮的黑白对比高光条。

## 最小光影句式

```text
主光自画面左上方柔光入射，光比中等偏低；台面接触阴影窄而软；
不锈钢呈冷白环境反射，木材保留暖固有色与纤维漫反射，二者反射形态明显不同。
```

## 自检

- [ ] 能否指出主光从哪来、软还是硬
- [ ] 是否写了接触阴影
- [ ] 至少两种材质的反射差是否可区分


## 系列光

系列规则表定了「侧上柔光、光比收窄」后，单张只调强度，不改主光家族。戏剧高反差若只出现在一张主图，须用户同意破例。
