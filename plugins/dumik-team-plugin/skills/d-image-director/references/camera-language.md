# 相机参数作视觉语言

焦距、光圈数字在此是**画面意图**，不是必须可还原的 EXIF。写清意图，慎堆参数。

## 常用视觉语言对照

| 说法 | 画面意图 | 电商注意 |
| --- | --- | --- |
| 标准–中长焦感 | 透视自然、主体稳 | 主图默认更安全 |
| 浅景深 | 主体清、背景柔 | 卖点区（Logo/接口）须仍可读 |
| 全清晰/小光圈感 | 前后都清 | 详情结构说明常用 |
| 微距 | 材质与工艺特写 | 仍锁局部比例，勿拉形 |
| 广角 | 空间夸张、边缘拉伸 | **慎用**：易导致产品畸变，结构验收失败 |

## 机位清单（写 Prompt 前勾选）

- 俯仰：平视 / 微俯 / 顶视 /（避免无意义仰视）
- 景别：全貌 / 3/4 / 局部
- 主体占比：约 __%
- 透视：自然 / 允许轻微空间感 / **禁止强广角畸变**

## 禁止与慎用

1. 无设计理由的超广角「酷透视」导致锅耳、刀柄弯曲。
2. 只写 `85mm f/1.4` 却不写清晰主体与背景关系。
3. 浅景深虚掉用户点名的卖点文字区或接口。

## 句式

```text
微俯 3/4，中近景，主体约占 50%；透视自然，禁止广角畸变；
产品锐利，台面后景轻微分层虚化，Logo 占位仍可辨位置。
```

与系列规则表中的「镜头气质」冲突时，以系列表为准，单张只调裁切松紧。


## 与系列镜头气质

系列规则表已写「微俯 3/4」时，单张不得改成顶视炫技除非用户点名。裁切松紧可调，俯仰家族保持。

## 参数堆砌自检

打开 Prompt，数一数 mm / f 数字：若超过 2 个且没有一句清晰/虚化意图 → 删参数，改写意图。
电商主图默认：**自然透视 + 主体锐利 + 禁止强广角畸变**。

## 高阶商业构图母型库（选型即写死几何结构，禁止“杂志感/高级构图”虚词）

写场景或棚拍 Prompt 前，除定俯仰与景别外，**必须选定 1 个具体构图母型**，写清谁被裁边、光带从哪切入、前景谁作遮挡或导视线：

| 母型 | 核心几何与镜头语言 | 适用场景（详情/主图/KV） | 写 Prompt 必写关键字 |
| --- | --- | --- | --- |
| **1. 单侧建筑/人物前景偷窥框** | 镜头贴着近景边缘拍：画面左或右单侧 `15%–30%` 放实景门框、黑立柱、哑光柱体或人物暗部虚化肩发剪影，自然压住侧边杂乱，把视线推进中央亮区主产品 | 居家场景氛围、第一人称偷拍故事屏 | `画面[左/右]侧约1/4以虚化[门框/立柱/肩背剪影]作前景框，视线穿过前景落向中央受光产品` |
| **2. 半桌/半椅切边 + 空间纵深走廊** | **反展厅呆板全框**：圆桌或单人沙发刻意 `35%–50%` 裁出左/下画边，桌只放 `1–2` 件极克制道具，身后让出通透门廊、落地窗或亚麻竖帘空间纵深，拉伸大牌建筑呼吸感 | 首屏门面 KV、大空间生活美学 | `桌缘大胆斜切出画左下角，桌面只留主杯与1件配饰，后景让出挑高窗帘与走廊自然纵深` |
| **3. 对角光带切割与明暗楔形** | 让一束柔边斜向晨光或百叶窗条纹直接斜劈过墙面/深色台面/坐垫，形成暗角与亮楔对冲；**用光束本身指向主产品**，顺带把暗角或净墙面留给后期压字 | 质感氛围屏、耐脏/材质高反差特写 | `一束斜向上午阳光自[方向]斜切台面与墙面，光束端精准打亮主杯，其余退入低反差柔暗区` |
| **4. 桌面 L/Z 型对角导视线** | 微俯 `35°–50°` 桌角俯拍：两件配饰一左上、一右下占住对角，中央留出净口袋稳放主杯；**用 1 支细长线性道具（银勺、铅笔、笔记本斜脊、灯臂）斜指杯底但不接触** | 桌面办公/阅读饮水、多人视角分享 | `配饰沿对角轻落边角，中央桌心清透；一柄[银勺/铅笔]呈斜角轻微指向杯身但不碰触` |
| **5. 「去脸不失人」局部触碰与悬停对位** | 人物不露全脸：可裁「鼻尖唇线至大腿」时装局部、手背轻掠提环、手臂平伸入画将杯身**悬停在平放杯盖正上方 `10cm` 垂直对位**、或坐姿屈膝直接作金属器皿支点 | 便携防漏开盖、单手轻量、人体工学 | `人物[仅截手臂/唇线以下时装/屈膝作支点]，指尖轻捏/悬停于平放杯盖正上方形成竖向呼应` |
| **6. 器物内框对称夹抱（托特包/书拱）** | 利用**敞开通勤托特包 V 型双隔层**（左右夹着平板与笔记本）、或**硬壳翻开书本搭出的建筑三角拱**直接做天然相框，把主杯稳立于包口/书拱视觉重心 | 通勤防漏便携、极简静物创意摆拍 | `主杯直立卡入敞开焦糖皮托特包中央隔层，两侧对称探出银色笔记本边缘形成 V 型天然夹框` |
| **7. 概念斜倚平衡与多层天际台** | 非生活场景的工艺/对比屏专用：用粗糙岩石/哑光建筑方台、倒扣底座或精密金属薄片做成高低错落阶梯，搭配微倾斜支撑张力与大面积浅调渐变天幕/百叶窗竖线背板 | 材料金字塔、结构剖面、超级符号 | `极简建筑材质高低阶台错落构图，无多余生活杂物，上方延展连贯柔和浅灰/奶白净墙负空间` |
| **8. `90°` 上帝俯视大色块围合** | 正垂直 `90°` 俯拍：用 `70%+` 连续大色块实底（微水泥地面、大面积木纹/深灰地垫或餐桌角落）包住中心少量聚焦人物手部动作或器物，极易排版且辨识极强 | 大场景行为互动、多杯陈列对比 | `90度正垂直俯拍，大面积连贯净色台面/地面占画面70%，中央紧缩聚焦手部与器物动作` |

## 前景裁剪、留白与道具克制铁律

1. **宁缺毋滥「桌上 ≤ 3」原则**：高端静奢桌搭靠的是留白与材质精度而非堆满桌面。单张桌上除主产品外，**次要配件群组严格不超过 3 件**（如仅 `1本精装书/皮垫 + 1只台灯 + 1小杯/眼镜`），严禁同时铺满鲜花、零食盘、杂物盒与多余电子设备。
2. **一屏一主型 + 竖向相邻禁止撞车**：同项目详情页相邻两屏不得选用同一种构图母型（如不能连续两屏用「桌面 L/Z 型导视线」），必须切换为「单侧前景框 → 概念阶梯 → 悬停对位手部特写 → 半桌+走廊纵深」。
3. **纯净负空间自然延展（防硬拼接）**：压字负空间必须靠「挑高净墙 / 柔和光带衰减 / 大色块台面自然向画边延伸」给出，**禁止写百分比分割线或刻意拉出白框**；大面积亮调壁面配深色主体、斜光带落暗处配合亮字，永远服从主光方向一致。
