# 相机参数作视觉语言

焦距、光圈数字在此是**画面意图**，不是必须可还原的 EXIF。写清意图，慎堆参数。

## 常用视觉语言对照

| 说法 | 画面意图 | 电商注意 |
| --- | --- | --- |
| 标准–中长焦感 | 透视自然、主体稳 | 主图默认更安全 |
| 浅景深 | 主体清、背景柔 | 卖点区（Logo/接口）须仍可读 |
| 全清晰/小光圈感 | 前后都清 | 详情结构说明常用 |
| 微距 | 材质与工艺特写 | 仍锁局部比例，勿拉形 |
| 广角 | 空间夸张、边缘拉伸 | **慎用**：易导致产品畸变，结构验收失败 |

## 机位清单（写 Prompt 前勾选）

- 俯仰：平视 / 微俯 / 顶视 /（避免无意义仰视）
- 景别：全貌 / 3/4 / 局部
- 主体占比：约 __%
- 透视：自然 / 允许轻微空间感 / **禁止强广角畸变**

## 禁止与慎用

1. 无设计理由的超广角「酷透视」导致锅耳、刀柄弯曲。
2. 只写 `85mm f/1.4` 却不写清晰主体与背景关系。
3. 浅景深虚掉用户点名的卖点文字区或接口。

## 句式

```text
微俯 3/4，中近景，主体约占 50%；透视自然，禁止广角畸变；
产品锐利，台面后景轻微分层虚化，Logo 占位仍可辨位置。
```

与系列规则表中的「镜头气质」冲突时，以系列表为准，单张只调裁切松紧。


## 与系列镜头气质

系列规则表已写「微俯 3/4」时，单张不得改成顶视炫技除非用户点名。裁切松紧可调，俯仰家族保持。

## 参数堆砌自检

打开 Prompt，数一数 mm / f 数字：若超过 2 个且没有一句清晰/虚化意图 → 删参数，改写意图。
电商主图默认：**自然透视 + 主体锐利 + 禁止强广角畸变**。
