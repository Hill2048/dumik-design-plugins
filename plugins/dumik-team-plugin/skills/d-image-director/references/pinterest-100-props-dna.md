# Pinterest 100 张静奢高定摆件材质物理手册（v0.3.0 · 纯本体版）

> 聚焦**摆件本身的工业/手作材质微物理、雕塑轮廓与项目赛道匹配**；光线方向、相机焦段与台面背景一律服从项目 `design.md` 与 `d-image-director` 主规约。内置 4 张 `3×3` 高清摆件垫图板（36 格 `1024×1024`）见 `assets/moodboards/摆件_01~04_*.jpg`。

## 一、六大摆件材质的微观物理细节（告别塑料玩具与粗糙土陶）

| 摆件材质 | 必须写入的微观工艺与质感线索 | 绝对禁区 |
| --- | --- | --- |
| **1. CNC 拉丝 / 喷砂金属** | 极细线性拉丝微纹 + 0.5mm 精密机械倒角微亮边 + 低饱和冷银/钛灰金属漫反射（非刺眼镜面） | 廉价电镀塑料反光、灰扑扑无金属体量 |
| **2. 无铁光学水晶 / 磨砂玻璃** | 纯无色无铁零青绿切边、精密几何棱面干净折射；磨砂吹制玻璃呈细腻雾面柔光过渡，无杂质气泡 | 普通玻璃青绿脏边、浑浊亚克力感 |
| **3. 薄胎哑光骨瓷 / 窑变素陶** | 薄胎利落收口、温润半哑蛋壳瓷釉、极克制手拉坯微弧；深炭黑/暖象牙素色无花纹 | 厚重粗糙农家土陶、刺眼高光白塑 |
| **4. 天然洞石 / 哑光大理石** | 真实天然细微矿石孔洞 + 低对比度温润石脉 + 哑光平切倒角，沉稳压台感 | 假贴图塑料大理石、打蜡发亮感 |
| **5. 极简棉纸画册 / 亚麻织物** | 细腻棉纸纤维肌理 + 极简无字盲印几何压凹 + 利落直角书脊 | 乱码假英文字母封面、反光铜版纸 |
| **6. 雕塑单枝植物** | 仅 1~2 枝建筑感线性枝干（单支纯白马蹄莲 / 极简绿果枝），低饱和墨绿叶色与大面积留白 | 菜市场大束鲜花、荧光塑料假叶 |

## 二、造型轮廓与赛道匹配铁律

1. **拒绝平庸基础几何**：不写“普通圆盘/普通小瓶”；指定**偏心凹槽 CNC 铣削托盘、修长高足薄胎果盘、八边形阶梯切面光学水晶垫、双层交错洞石托座、细颈磨砂单枝花器、建筑悬浮折角哑黑香座**。
2. **按项目 `design.md` 风格赛道匹配**：现代静奢/科技单品（纯钛杯、数码、厨电）严禁混入斑点粗陶与深色老木；单屏摆件 ≤3 件，绝不抢主品戏份。
