# 提示词分段顺序与权重

写完整 Prompt 时按下列顺序组织信息；可压缩成一段，但**优先级顺序不变**。交付格式仍遵守 `prompt-contract.md`（比例行、@图职责、末尾禁止段）。

## 推荐分段顺序

| 序 | 段 | 写什么 | 不写什么 |
| --- | --- | --- | --- |
| 1 | 风格/媒介气质 | 摄影、商业棚拍、电商主图气质等**已确认**方向 | 空洞「高级」「高级感」 |
| 2 | 主体锁 | 产品是谁、结构保留、固有色、Logo 占位 | 重设计外形 |
| 3 | 场景 | 台面、环境、次要道具；标明自由区边界 | 未授权的第二主产品 |
| 4 | 机位 | 俯仰、远近、主体占比、裁切 | 乱广角炫技（见 `camera-language.md`） |
| 5 | 光影 | 光源方向、软硬、光比、接触阴影 | 「电影感」不落地 |
| 6 | 材质 | 光打在表面的结果：反射、粗糙度、纹理 | 只堆「油润质感」 |
| 7 | 质量收口 | 清晰主体、边缘干净、可读卖点区 | 无意义的 8k/masterpiece 堆砌 |
| 8 | 禁止 | 本任务真实风险（见控制层负面段） | 超长通用 negative |

最短写法：段 2+5+6+8 不能缺；段 1/3/4 有设定或用户要求时再写满。

## 权重（非迷信符号）

模型没有统一可靠的 `(word:1.3)` 魔法；用**信息设计**加权重：

1. **位置靠前**：结构锁、不可改项放在主指令前半；氛围放中后。
2. **描述加密**：关键部件用具体名词 + 可见关系（「三孔接口相对把手呈等边」），不要只重复「保持一致」。
3. **重复只用于冲突点**：同一控制点最多再收口一次（末尾禁止或一句「保留…」），禁止整段复制三遍。
4. **慎用括号权重符号**：目标接口若不支持或表现不稳，不要依赖 `(masterpiece:1.5)`；改写清楚可见结果。
5. **参考图职责 > 形容词**：`@图1 锁结构` 的效力通常高于「极其极其真实」。

## 填空骨架（可复制后删空项）

```text
比例：2:3
@图1：结构真源。@图2：光/氛围参考（若有）。

[风格] …
以 @图1 锁定产品[轮廓/部件/固有色/Logo 占位]；[场景一句 + 自由区边界]。
机位：[俯仰/景别/主体占比]。
光影：[主光方向与软硬]；保留接触阴影与材质反射差。
材质：[各表面光结果]。
[质量一句]。
禁止：…
```

## 与六段结构的关系

若用户或模板要求「主体→风格→光影→构图→媒介→参数」叙事顺序，见 `six-structure.md`；**控制优先级仍以本文件序 2 主体锁为先**，叙事顺序可以按六段排版，不可把风格压过结构锁。

## 自检

- [ ] 打开 Prompt：前 30% 是否已出现结构/不可改项
- [ ] 禁止段是否只含本图风险
- [ ] 是否没有依赖未经验证的权重符号当唯一控制手段


## 压缩规则

字数紧张时合并段，但合并后仍须能指出：主体锁句、光影句、禁止句。删段优先删质量堆砌词，最后才动主体锁。
