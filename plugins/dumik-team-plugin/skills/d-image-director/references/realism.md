# 真实感：世界逻辑与轻微不完美

「很真实」要写成世界里说得通的细节，不是堆「realistic, 8k」。

## 世界逻辑（先满足）

1. 重力与支撑：物体坐实，无悬浮。
2. 尺度：手、餐具、台面与产品比例合理。
3. 因果光：影子方向与主光一致；镜面反射来源说得通。
4. 材料行为：湿区、油渍、高温变色仅在用户要求的功能态出现。
5. 使用痕迹：仅当品牌允许「生活感」时加；专业冷峻系列默认干净。
6. 透明玻璃与对比实验铁律：透明容器/实验缸/护盾必须采用**零青绿杂色的纯无色低铁光学石英水晶**（切边仅呈透明白/浅暖银折光，禁发绿廉价玻璃边）；双仓防锈/抗腐/保鲜对比须让**介质本身强化左洁净 vs 右污染**（如左无色清澈净水 vs 右浑浊发黄锈水+沉渣，禁两仓同灌红茶/深色液掩盖反差）；跨接实验缸的左右拼色基座须**严丝合缝零竖缝**，水中产品须 **100% 稳坐缸底不悬浮**。

## 轻微不完美（可选增强）

在**不破坏 P0 结构**的前提下，可加微量：

- 台面极淡纹理或细尘（克制）
- 金属高光内很弱的环境色溢出
- 布料或纸张微褶

禁止：脏污毁卖点、随机破损、歪曲 Logo、畸形解剖。

## 反模式

- 只有「超真实、细节拉满」无世界逻辑。
- 为真实感牺牲结构锁（「更有手作感」却改了锅耳）。
- 同时开启脏乱生活感与无菌棚拍高级 — 选一个系列调性。
- 把带 CG 磨皮感的 AI 场景图当主底图反复垫，或滥用大光圈奶油虚化与人工假白烟。

## 真机实拍感与情绪标准（实景生活屏推荐）

1. **垫图源决定真实感上限**：写实生活屏优先直接垫干净的真机实拍参考图（如用户 Eagle 参考库）借其镜头畸变、光学与自然微瑕疵，再定向替换木纹/杂物为项目材质；避免拿带 AI 磨皮感的场景卡反复垫底。
2. **焦距景深与微颗粒**：优先写「35mm f/4–f/5.6 小光圈日常随手拍大景深，前后景自然清晰微衰减 + 真实相机轻微传感器颗粒」，明确禁止过度奶油散景虚化。
3. **真实环境金属反光与微瑕疵**：金属表面必须映出真实窗格亮块与室内不规则暗部倒影（禁均匀 CG 球面高光）；书页保留微翘纸边与极简印刷肌理；**彻底禁画人工假白烟**。
4. **必须传达明确情绪**：无论是晴朗上午暖阳的积极感还是午后斜阳的松弛安静感，画面都要有清晰温度与空间层次（艺术漆/微水泥墙光影、建筑层次、立体圈绒地毯），严禁拍成阴天灰沉或光秃冷白毛坯墙。

## 句式

```text
产品稳置于台面，接触阴影与主光方向一致；金属反射来自场景窗光，
木材保留暖固有色；允许台面极轻微纹理，保持主体清洁可售卖。
```


## 分品类提示（可选）

| 品类 | 世界逻辑重点 | 轻微不完美慎用 |
| --- | --- | --- |
| 锅具 | 坐实台面；内壁反射来源说得通 | 油渍仅功能态 |
| 刀具 | 刃线笔直逻辑；手柄握感接触 | 勿假锈毁卖点 |
| 筷/餐具 | 成对尺度一致；握姿遮挡可控 | 勿脏乱 |
| 砧板 | 厚度透视；纹理方向连续 | 裂纹仅当卖点证明需要 |

## 与验收

真实感加减分不进入 `d-consistency-check` 结构三态，除非真实感手段已经改坏 P0（例如为「手作感」扭了外轮廓）。
