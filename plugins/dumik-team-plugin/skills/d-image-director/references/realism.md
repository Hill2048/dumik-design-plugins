# 真实感：世界逻辑与轻微不完美

「很真实」要写成世界里说得通的细节，不是堆「realistic, 8k」。

## 世界逻辑（先满足）

1. 重力与支撑：物体坐实，无悬浮。
2. 尺度：手、餐具、台面与产品比例合理。
3. 因果光：影子方向与主光一致；镜面反射来源说得通。
4. 材料行为：湿区、油渍、高温变色仅在用户要求的功能态出现。
5. 使用痕迹：仅当品牌允许「生活感」时加；专业冷峻系列默认干净。

## 轻微不完美（可选增强）

在**不破坏 P0 结构**的前提下，可加微量：

- 台面极淡纹理或细尘（克制）
- 金属高光内很弱的环境色溢出
- 布料或纸张微褶

禁止：脏污毁卖点、随机破损、歪曲 Logo、畸形解剖。

## 反模式

- 只有「超真实、细节拉满」无世界逻辑。
- 为真实感牺牲结构锁（「更有手作感」却改了锅耳）。
- 同时开启脏乱生活感与无菌棚拍高级 — 选一个系列调性。

## 句式

```text
产品稳置于台面，接触阴影与主光方向一致；金属反射来自场景窗光，
木材保留暖固有色；允许台面极轻微纹理，保持主体清洁可售卖。
```


## 分品类提示（可选）

| 品类 | 世界逻辑重点 | 轻微不完美慎用 |
| --- | --- | --- |
| 锅具 | 坐实台面；内壁反射来源说得通 | 油渍仅功能态 |
| 刀具 | 刃线笔直逻辑；手柄握感接触 | 勿假锈毁卖点 |
| 筷/餐具 | 成对尺度一致；握姿遮挡可控 | 勿脏乱 |
| 砧板 | 厚度透视；纹理方向连续 | 裂纹仅当卖点证明需要 |

## 与验收

真实感加减分不进入 `d-consistency-check` 结构三态，除非真实感手段已经改坏 P0（例如为「手作感」扭了外轮廓）。
