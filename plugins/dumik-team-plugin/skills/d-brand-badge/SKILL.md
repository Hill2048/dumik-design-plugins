# DUMIK 品牌风格 3D 扁六边形徽章设计师（d-brand-badge）

本 skill 专门打造与 **DUMIK 品牌标牌、纯钛 100% 标题标贴、婴童品质/减重 40% 徽章** 完全同一家族血统的 **品牌修长扁六边形 3D 高定金属徽章**，彻底解决 AI 做品牌徽章时常见的「轮廓画胖变盾牌、宋体花边跑偏风格、英文抢戏压扁中文、单层金板层次弱、外圈银边太粗太笨重、图标悬空呆板」六大通病。

> **与 `d-badge-wash` 的分工**：
> - 仅想保留原徽章外形（如原圆形、原国标盾形），只脱壳换当前项目材质 → 用 `d-badge-wash`；
> - 要**新设计或重塑为 DUMIK 品牌修长扁六边形 3D 金属徽章/认证标/卖点角标/数据标** → 一律用本 skill `d-brand-badge`。

## 六大不可破设计铁律（实战踩坑沉淀）

1. **轮廓铁律（品牌修长扁六边形，绝不变胖）**：
   - 外廓必须 100% 锁死 `01_品牌扁六边形镜面金标牌.jpg` 的**修长横扁对称六边形**（宽高比约 `2.5:1 ~ 2.7:1`，上下正中钝角凌厉舒展、四条长斜边笔直利落、左右竖边短促微圆角）；
   - **严禁**画成胖盾牌、等边正六边形、复古八边形或加飘带丝带。
2. **字体铁律（当代极简无衬线，严禁复古化）**：
   - 中文统一采用**当代极简几何无衬线黑体**（笔画干净利落、厚实有立体浮雕存在感，对齐项目标题标贴与 `减重40%` / `婴童品质`）；英文采用极简全大写无衬线体；
   - **严禁**宋体/衬线体、手写体、复古欧式飘带或多余菱形星点花边。
3. **主次铁律（中文与 ICON 绝对霸主，英文大幅退让）**：
   - 电商详情页角标 0.5 秒看懂全靠 **核心中文 + 直观 ICON（或超大数字）**，深暖黑咖下沉内盘必须大幅撑大占整枚徽章 **75%+ 视觉重心**；
   - 如有英文副标（如 `HEALTH & AESTHETICS`），**字号大幅缩小至中文高度约 1/4、笔画极纤细**，低调伏在顶部收窄后的镜面金斜边环上做腕表级小刻字，绝不喧宾夺主；无英文需求时不硬凑英文。
4. **一体连铸与去杂线（告别呆板悬空拼贴）**：
   - **默认移除内盘中间竖分隔线**，保持深色下沉内盘整洁通透，把宽度全释放给大中文与大 ICON；
   - **图标底沿一体连铸**：左侧单线/剪影 ICON 适当放大下沉，使其底部轮廓线条**顺势无缝熔接连铸进下方扁六边形金色内框斜边**（像高定珠宝一体压铸浮雕），彻底消除图标孤立悬空感；若是纯数字/数据型卖点（如 `减重 ↓40%`），则采用顶副词 + 下方超大立体切角数字填满内盘。
5. **三材质四层精工结构 & 极薄银边铁律**：
   - **严禁**整块单层实心金板直接凹刻（层次单薄），也**严禁**外圈冷银底托过粗过厚显笨重；
   - 标配 **三材质四层结构**（细节与提示词写法见 `references/brand-badge-system.md`）：
     1. **最外沿底托**：发丝级极致纤薄的 **316L 抛光冷银精钢薄底托边**（仅外沿微露一线锐利黑白金属棱）；
     2. **主外环**：零颗粒极度丝滑的 **液态高光镜面淡香槟金**（微弧抛光面带强柔光箱扫光反差：清透浅香槟白金高光平滑扫向底部醇厚深黑咖渐变暖琥珀金暗带，零拉丝零粗糙颗粒；顶部窄环小英文做深暖咖精密蚀刻凹字）；
     3. **下沉内盘**：零颗粒极度丝滑的 **深暖黑咖哑光烤漆下沉底盘**（带克制温润微漫反射），沿内盘下沉台阶镶嵌一圈锐利液态镜面香槟金内折光细棱；
     4. **前景立体浮雕**：内盘中的超大中文、大数字与一体连铸 ICON 全部做**独立凸起的液态高光镜面淡香槟金立体浮雕金属件**（带 CNC 微倒角高光切面与紧贴烤漆底的极微弱接触影）。
6. **强制「先平面确认 → 逐字零错门 → 再出 3D」闭环与授权门**：
   - **未获用户本轮明确下令「开始 / 生成 / 跑」前，绝不调用付费生图接口**；
   - **Step 1（纯色 2D 平面版式确认）**：必先输出极净纯白底黑白灰三色 2D 矢量平面稿（多方向探索用 `1:1` 竖排 3 案满宽对比；方向已定时直接出 `16:9` · `2K` 满幅单图），**必须经用户确认版式并逐字逐字母核验 100% 零错拼、零缺笔**；
   - **零成本局部精修技巧**：若 Step 1 平面稿整体排版完美，仅出现单字母小错拼（如 `AESTHETICS` 缺横）、外银边偏粗、多出细竖线或需局部微调缩放/对齐时，**优先用本地 Python（PIL / numpy）在纯色平面图上 0 成本像素级精准修补并 `read_file` 复核**，不盲目重抽浪费额度或弄丢完美构图；
   - **Step 2（3D Octane Render 渲染）**：严禁再塞入旧原图或废稿，只传 **`@图1`（验收通过的纯色平面真源）+ `@图2`（内置 `01_品牌扁六边形镜面金标牌.jpg`）+ `@图3`（内置 `04_液态镜面金铭牌局部.jpg` 或对应同类标杆 `02`/`03`）**，通过 `d-image-runner` 走 DesignFlow **`Banana 2.1` · `16:9` · `2K` · `x2`**，输出正正面平视居中、极净纯白底（`#FFFFFF`）成品。
   - **分层归档铁律（严禁把单屏徽章混进品牌资产）**：
     - **全案跨屏复用级**（品牌标牌、超级符号、全案通用标题标贴）→ 归档 `设定集/品牌资产/`；
     - **单屏专属级**（只服务某一卖点屏的数据标/认证标/ICON，如 `S15` 减重 40%、`S06` 婴童/安全检测、`S14` 温度计/雪花）→ 一律归档对应屏 `制作/<编号_名称>/局部配件/`，并在 `assets.md` 单列「单屏专属配件」分区登记（写完整相对路径，严禁简写 `_02.jpg`），不污染 `设定集/品牌资产/` 与 `project.md` 屏数。

## 标准四步工作流

1. **需求拆解与原型选型**：明确徽章归属（全案复用 vs 单屏专属 `<编号_名称>`）及 `[画内字白名单]`（主中文、可选副英文、核心图标/数字），对照 `references/brand-badge-system.md` 选定 4 大原型之一；若用户未明确授权，先给 ≤5 行极简方案确认。
2. **Step 1 平面版式设计与验收门**：授权后出纯平黑白灰三色 2D 矢量稿 → `read_file` 逐字逐笔核验（零错字、品牌扁六边形不发胖、中文与 ICON 够大、英文够小够细、极薄灰边、无多余竖线）→ 如有局部小微调优先零成本脚本修准 → 请用户确认平面稿后按归属落盘 `<归属目录>/<编号>_<名称>_纯色平面图.png`。
3. **Step 2 三材质四层 3D 渲染**：严禁再传旧图，仅喂 `@图1` 平面真源 + 内置液态镜面金标杆图 → `d-image-runner`（`Banana 2.1` · `16:9` · `2K` · `x2`）生成纯白底 3D Octane 成品。
4. **终检与分层归档**：`read_file` 逐字复核拼写、笔画、四层材质反光、极薄冷银托边与纯白底纯净度 → 按归属落盘 `<归属目录>/<编号>_<名称>_3D_Octane_01.jpg`（及 `_02.jpg`）→ 若需直接交付透明底 PNG / 2 层 PSD 给 PS 排版，无缝衔接 `d-cutout`（扁六边形实心徽章推荐 `--no-holes` 0.5 秒无损精抠并保护极薄冷银外环零啃边）→ 以完整相对路径登记入 `assets.md` 对应分区（清理 `%TEMP%\dumik-runs\` 临时文件）。
