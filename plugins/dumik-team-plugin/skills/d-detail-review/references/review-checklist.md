# 详情/主图终稿六维审查细则与标注 Schema

## 一、六维强制审查清单（缺一不可）

### 1. 错别字与老模板残留（`error` 🔴）
- 产品品类串戏：例如马克杯详情页里残余“炒锅 / 锅盖 / 锅身 / 实木把手 / 乌檀木 / 保鲜盒 / 食物 / 18cm / 0.467kg”等老模板文案或局部旧图。
- 材质表述自我降级或冲突：如本品为「内外 100% 纯钛」，却残留「内壁纯钛板材」。
- 同一模块写串词：如四宫格里把「钛轻量」错写成「钛抗菌」造成重复。
- 重复贴图与套错检测报告：同一份报告编号重复贴两屏、报告正文检测项（如化学成分表）与放大镜宣称（如抗菌率 ≥99.9%）对不上。

### 2. 对照飞书策划原图（`error` 🔴 / `missing` 🟠）
- 逐屏打开 `素材/飞书画布/S01_画布原图.png` ~ `Sxx_画布原图.png`（及 `M01~M06` / `E01`）核对：
  - **蓝框/白框/绿框叠改词优先于底图旧字**（运营常在老模板截图上盖框改文案）。
  - 核对主标题、副标题、卖点短语、剖面层级名、细节小图说明是否齐全。
  - 核对产品参数屏（`S20`）、底部合规注释屏（`S21`）、收尾规格条（`S22`）是否完整落地；**同时反向纠偏策划原稿里的低级错字**（如 `锅内采用100%`、`小于≤0.2%`），在审稿卡片中明确提醒。

### 3. 数据、参数与专业知识核对（`error` 🔴）
- 以 `project.md`「唯一实测规格真源」核对全部数字：容量、尺寸（直径/高度）、重量（无盖/带盖）、抗菌率、保温/保冰时长、减重百分比。
- 交叉校验数字逻辑：例如 `150g vs 250g` 是减重 `40%`，不可在旁边写“仅不锈钢的一半重（50%）”。
- 专业标准零容忍：金属牌号（中国国标 `TA1~TA4` vs 美国/国际 `Gr1~Gr4`）、表头列对齐、化学符号（`Ti` 而非 `TI`/`ti`）、单位大小写统一（`150g` 与 `250g` 不可混用 `150G`）。

### 4. 图文一致性核对（`error` 🔴 / `warn` 🔵）
- 结构动作与实物白底图一致：实物是旋转拨片盖（盖面有双弧箭头），文案若写“滑动开合/左右推”必须标出提醒与运营同步修正。
- 数量一致：英文/小标写 `Five Advantages` 但下方只排了 3 个标签；对比图视觉状态与文案描述一致。

### 5. 电商广告法合规与 `*` 号闭环（一律判 `error` 🔴 红灯必改，严禁降级为蓝灯）
- **高危绝对化/极限违禁词（一律标 🔴 红灯并给合规替换文案）**：
  - `行业领先`、`第一`、`唯一`、`顶级`、`极致`、`最佳`、`100%无菌`、`无菌空间`、`国家级`、`国家权威`、`永久`、`绝对`。
  - 医疗功效暗示词（除非有特批资质）：`杀菌`、`灭菌`、`消毒`、`防癌`、`抗菌率100%`。
- **对比实验免责声明（缺即标 🔴 红灯）**：凡含 6h/8h 锁温保冰对比、24h 茶水浸泡对比、减重对比，须核对是否附带「数据来源实验室 / 对比款说明 / 闭盖 vs 敞口测试条件说明」。
- **星号 `*` 闭环（悬空即标 🔴 红灯）**：正文所有带 `*` 的宣称，文末注释屏必须逐条对应释义，严禁悬空 `*`。

### 6. 排版、断行与空白占位检查（`missing` 🟠 / `warn` 🔵）
- 空白框架/白板未贴图（如报告立牌空白、四宫格空白、空渐变胶囊未填字）。
- 相邻屏大标题重复撞车（如 `S01` 与 `S02` 连续出现完全一样的超大主标题）。
- 孤字断行（如 `一些无法忽视 / 的细节`）、大段无意义纯空白过渡带。

## 二、像素取框精度规范

1. 必须先用 `slice_for_review.py` 生成带标尺的条带图（顶部为原图 `X` 刻度，左侧为原图绝对 `Y` 刻度）。
2. 读取条带后，直接根据刻度尺读出错误目标在原图上的 `[x1, y1, x2, y2]`：
   - 外扩 `8~16px` 留呼吸感，不压住核心文字笔画；
   - 严禁把标尺边距（`left_margin` / `top_margin`）算进坐标——脚本画的刻度数字就是**原图真实像素坐标**，直接照读即可！
3. `build_review_board.py` 会自动对 `bbox` 做边界裁剪（clamp 到图片尺寸内）并按 `y1` 自动排号或保留指定 `id`。
