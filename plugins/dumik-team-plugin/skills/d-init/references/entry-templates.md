# 项目入口三文档模板（精简覆盖态）

`init_dumik_project.py` 会基于本规范自动生成与维护项目根目录三文档。维护已有项目时，先读原文件再做局部修改，保留项目差异，不整份覆盖已有设定。

- 根目录永远只放 `AGENTS.md`、`project.md`、`design.md` 三份文件，不新建 `CLAUDE.md`、`CURRENT_PROJECT.md`、`CONTEXT.md`、`拆解清单.md` 或任何 `.json` 状态队列。
- `AGENTS.md` 仅内联 `@[design.md](design.md)`（保证展开总字节远低于 `24KB` 截断线，视觉宪法永不丢失）；`project.md` 作为大账本按编号用 `read_file` 或 `--status` 按需读取。

## 一、根目录 `AGENTS.md` 模板（`init_dumik_project.py` 默认生成）

```markdown
# <项目名> — 项目工作规约

- 本目录即独立项目根，不建跨项目指针或历史日志。
- **9:16 纯无字画面底图**：除产品原生丝印/刻字外，严禁任何文字、数字标尺、角标与引线，按 `project.md` 留白。
- **零运行垃圾**：禁写 `.json` 队列、`拆解清单.md` 或运行记录；制作只按需建 `制作/<编号_名称>/prompt.md` 覆盖维护最新版。
- **参考与授权**：白底只锁结构固有色；光色从 `design.md` 与 `设定集/`；飞书参考图只读不喂 API；未收「开始生图/出图」绝不调付费接口。
- **汇报带短卖点**：列编号必附4~6字卖点（如 `S01 健康对比`），一眼扫完，忌裸号或长句。
- **防截断按需读账本**：`project.md` 体量大，不整本内联，按当前编号按需读取或跑 `--status`。

## 项目上下文自动挂载

@[design.md](design.md)
```

## 二、根目录 `design.md` 模板（全案视觉宪法）

未知的材质光学参数、光影和台面规则必须保持「待定调」，**严禁根据白底图的棚拍白背景猜测场景风格**。里程碑定调完成后才锁定写入：

```markdown
# <项目名> — 视觉宪法

- 当前锁定状态：待补齐白底参考与里程碑定调

## 一、产品身份锁（7 维解剖档案 · 严禁漂移）

- 白底结构基准图（优先补齐正视/侧视/顶视/底视/内腔五视图或身份卡）：
  - 待补齐（放入 `设定集/白底图/`）
- **外轮廓与比例**：精确尺寸与视觉比例（壁厚/底角弧度）｜禁画变形雷区：待看白底图填实
- **表面材质与微观肌理**：固有色、微观纹理颗粒/反差/受光折射与边缘高光（写清与易错材质的区别）：待看白底图填实
- **关键部件解剖表**（看不见的视角标「待补视角」绝不瞎编）：
  - 部件｜位置与连接方式｜精准形态、厚度倒角与细部结构｜易错禁画
- **原生 Logo / 刻字 / 钢印落位**：文字内容、所在面、工艺与比例：待看白底图填实
- **状态切换规则**：无盖/合盖/装饮品/展开态各自保留或隐藏的部件：待填
- **按需摘取复用短句（只取本屏可见部位，画面拍不到的严禁写入提示词）**：
  - `主体基础`：仅写共用廓形与主材质（≤40 字）
  - `按需追加`：仅拍到对应面或处于对应状态时再拼入（无盖不提盖、不拍内底不提钢印、远景不提微刻）。

## 二、材质光学公式（第 0 批里程碑确认后锁死）

- 主材质光学表现：待定调（例：金属宽倒角漫反射/拉丝纹理、木材天然纤维暖色）
- 副材质与接触表现：待定调

## 三、统一空间与光影母版（第 0 批里程碑确认后锁死）

- 光影基调：待定调（光源方向、软硬光比、台面接触阴影）
- 色彩与台面材质家族：待定调
- 超级符号（视觉锤）：待定调

## 四、全案硬禁令

- 全画面严禁生成任何后期排版标题、卖点文案、数字标尺、指示引线、放大圆框、水印或装饰角标。
- 所有画面必须按 `project.md` 预留干净低反差的后期 PS 排版负空间。
```

## 三、根目录 `project.md` 五段式嵌图总账本（唯一真相）

由 `parse_feishu_canvas.py`（接飞书拆解）或 `init_dumik_project.py`（无飞书先建空表）直接维护，结构固定为五段，全表采用相对路径 `<img src="..." width="110">` 内联缩略图：

1. **头部元信息**：飞书源链接、商品参考链接、默认画幅 `9:16 竖版（纯无字底图，人工后期 PS 排版）`、参考图隔离铁律、各批统计；若有修改轮补丁置顶提醒。
2. **一、核心策划分析（卖点提纯与唯一规格真源）**：目标人群与痛点、三层购买转化逻辑、实测规格唯一真源、与 `必渲` 核心特写清单。
3. **二、第 0 批：视觉里程碑设定**：`MS01..MSk`，包含画幅、当前状态、定稿/参考路径、定调重点。
4. **三、3:4 主图转化序列（`M01..Mk`）**：嵌 `画布原参考` 缩略图、保留 `运营原主副标题 & 批注`（供判断留白与 PS 直接复制）、标注 `★由第 1 批 9:16 母片裁切派生（关联 Sxx）` 或独立生成、`当前出图` 缩略图与状态。
5. **四、详情页纵向叙事全表（`S01..Sn` 按买家下滑顺序一表顺排）**：用 `批次与关联` 列标出 `★第1批（同源 Mxx）` / `第2批` / `后期排版`，不断流保留纵向叙事，含 `画布原参考` 缩略图、`运营原主副标题 & 批注`、`纯无字底图拍法 & PS留白`、`机位景别`、`当前出图` 缩略图与实时状态（纯报告/参数屏标 `无需生图（后期排版）`）。
6. **五、第 3 批：独立 1:1 入口车图与 SKU 底图**：列出 `E01..Em` 与无法复用需独立出图的 1:1 入口/SKU 底图。
