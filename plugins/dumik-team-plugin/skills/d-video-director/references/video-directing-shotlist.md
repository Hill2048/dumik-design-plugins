# 导演与分镜方法：镜头表、节奏与连续性

> 来源：Higgsfield 官方生产实践（《Hell Grind》95 分钟长片）及其 shotlist / camera / motion 方法论整理。
> 本文只保留**导演调度与分镜构造**，已剔除平台工具、模型调用与参数枚举。
> 与 `directing-design.md` 配合使用：后者管单镜的观看关系，本文管整条序列的组织。

## 一、三层结构

一条完整的片子的提示词文档由三层组成，缺一层就会失控。

### 1. 全局风格前缀（Global Style Prefix）

一段**粘在每个提示词前面**的风格块。改一次，全片生效。它锁定：

```
画幅与分辨率 · 光照法则 · 色彩配比 · 镜头与快门 · 皮肤真实度
表演调性 · 物理规律 · 构图法则 · 连续性规则 · 帧率 · 声音约定
```

**DUMIK 用法**：把这段写进 `story_contract` 的固定部分，每镜复制。若用户给了自定义前缀，**逐字使用用户的**，不要改写。

### 2. 资产表（`@` 词表）

每个反复出现的资产**只声明一次**，给一个稳定 `@` 名：

```
@hero —— 主角
@boss —— 配角
@headphones —— 产品
@sneakers · @bag —— 道具
@kitchen · @street —— 场景
@s_hero_wet —— 主角的「跑后出汗」状态
```

**关键规则：多状态变体必须各自独立建条目。** 不要让模型「后面再让他出汗」——它会自己发挥，脸就漂了。

**每条资产还要带保真等级**（说明多少必须保留到像素）：

| 等级 | 含义 |
|---|---|
| `full-preserve` | 完整保留（产品、主角脸） |
| `partial-preserve` | 部分保留（点名哪些部位） |
| `attribute-transfer` | 属性迁移（把什么转移到什么上） |
| `loose-guide` | 松散引导（只参考气质） |

不写等级 = 「用 @image4 做那件外套」变成「模型今天心情好就保留」。

### 3. 具名分场提示词

每场编号（1、2、3…），再按 15 秒切块命名（`1a`、`1b`、`2a`）。

## 二、单场提示词的固定顺序

**严格按此顺序写，从上到下**：

```
[风格前缀 —— 整块，逐字]

角色：
[只写本镜出现的角色。@名 + 锁定的外貌描述 + 携带状态
（上一场湿的头发、单肩的背带、服装未变）]

画外（仅当有人刚离场）：
[上一镜在场、本镜不在的人：从哪侧出画 + 最后可见状态。
「Bo —— 从画面左侧出画，仍提着箱子。」只带一镜，连续两镜不在就删。]

场景：
[1—2 句。在哪、何时、以及空间走位 —— 每个角色相对场景和彼此的位置。
「主角在厨房岛台，背对镜头；摩卡壶在左边灶眼上。」]

切 1 —— [景别，焦段/视场角，镜头运动]：
[节拍级动作：手势、视线、呼吸、微停顿；镜头做什么；光做什么；现场音效]

切 2 —— …
```

**每段提示词目标 15 秒。** 不要用空镜头凑时长。

### 画外行是合法再入场的保障

携带状态只管「谁在画面里」，不管「谁刚走」。从错误一侧重新入场，是观众能感觉到但说不出的经典穿帮。每个离场角色写一行，下一段提示词就免费获得了正确的入场侧和手部状态。

### 用重复动作做匹配剪辑

独立生成的两场要能剪在一起时，让相邻场景**以同一个手势结束和开始**（比如同一个扶耳动作）。复用的运动让它们大概率能「动作切」。

## 三、节拍编排：不要写「他跳舞」

通用动作动词对模型毫无意义。要把动作拆开写：

```
差：他跳了一段舞。
好：跟着节拍两次清脆点头，肩膀依次后滚，膝盖轻沉，
    一个松弛的响指，最后收在四分之一转身。
```

## 四、密度判断：几个节拍装进一个 15 秒

这是镜头表里最难的判断。没有固定比例（正片实践从 1.4 行/提示词到 4.7 行/提示词都有）。

**满足以下全部条件时，合并成一个提示词：**

1. 画面内角色集合相同
2. 地点相同（或同一地点子区域）
3. 一个连续的情绪/时间单元 —— 无时间跳跃、无情绪转折
4. 15 秒内可演完
5. 合并后仍在实际长度上限内

**满足任一条件时，拆开：**

1. 地点硬切（公寓 → 闪回）
2. 主要角色进出场改变了处理清单
3. 镜头/机位变化需要自己的时间包（广角建立 → 紧特写插入）
4. 表演弧需要自己的 15 秒 —— 跨 5—7 个节拍累积的反应**绝不与动作打包**。**不要把悲伤切碎**：一次连续的情绪崩溃就是一个提示词，哪怕剧本写成三行。
5. 插入镜头/切出到道具或屏幕（这些要自己的大特写提示词）

**每段的复杂度预算**（超出即拆）：

- 强动作 > 2
- 镜头运动 > 2
- 重要角色 > 3
- 复杂视效事件 > 1
- 地点变化 > 1

**时长阶梯**：

| 时长 | 承载内容 |
|---|---|
| 4—8 秒 | 一个强动作 |
| 8—12 秒 | 一个动作 + 一次揭示 |
| 12—15 秒 | 2—3 个简单节拍 |
| 复杂打斗/追逐/变形 | 拆成多个提示词 |

**15 秒是默认信封，不是枷锁。** 若一场的节拍只填得满 4—8 秒，就生成一条更短的片子，不要把死气垫进 15 秒。

**拿不准时，偏向更多提示词、更短信封。** 模型处理紧凑提示词比过载提示词好得多。

## 五、序列检查：两道单镜看不到的关

### 1. 节奏预算（算术闸门）

写之前先算账：总时长 ÷ 每镜平均 4—6 秒 = 能承载的镜头数，并**预留一次刻意的长停留（6—8 秒）**给关键瞬间。

参考带：

| 总时长 | 镜头数 |
|---|---|
| ≤15 秒 | ~3 |
| ~20 秒 | 4—5 |
| ~30 秒 | ~6 |
| ~45 秒 | 7—8 |
| ~60 秒 | 9—11 |

**然后验算：各镜时长之和必须精确等于请求的总时长。** 加不上的预算 = 死气或不可能的镜头，而且这个错误在时间线上之前完全看不见。

### 2. 单调性审计（读列，不读提示词）

草稿写完后，**只读每一镜的「景别 + 镜头运动」那一行**，从上到下当成一列读。

**不允许连续三镜共用同一景别且同一镜头运动。** 当每一镜都读成「中景、缓慢推近」，要改变的是镜头的**功能与尺度**，不是时长。

单镜复核完全看不到这个失败；只有把列当成序列读才会暴露。这是生成式镜头表最常见的破绽。

## 六、机位与镜头运动

### 运动分类

| 类别 | 常见写法 |
|---|---|
| 推拉 | 推近、拉远、跟推 |
| 升降 | 摇臂升、摇臂降、垂直升降 |
| 环绕 | 环绕、浅弧、半圆 |
| 变焦 | 光学变焦、希区柯克变焦 |
| 跟随 | 跟随、贴身跟拍、追尾 |
| 特殊 | 穿物、FPV、子弹时间 |
| 时间 | 慢动作、延时、回弹变速 |

### 一条运动法则

**同一镜内不得同时 Dolly In + Dolly Out。** 这是最常见的自相矛盾写法。

### 双对比切镜规则

**每个切点必须同时改变景别与机位性格。** 只换景别不换机位性格，剪辑会「黏」；只换机位性格不换景别，会「跳」。

### 运动与情绪的对应

镜头运动应服务焦点的情绪：

- 压迫 → 缓慢推近
- 疏离 → 缓慢拉远
- 揭示 → 摇臂升 / 拉远后暴露
- 不安 → 手持微晃
- 决断 → 固定机位

### 微动作需要精确距离

写「轻微推近」时，补上距离量级（如「约 30 厘米」），否则模型会推成一个大特写。

## 七、连续性规则

- **跨切镜可稳定跟踪的角色不超过 3 个。**
- **出画即消失，画外即不存在。** 不要让镜头外元素在下一镜凭空出现。
- **避开反射面。** 镜面反射是 AI 视频最常见的崩坏点。
- **场景默认「进行中」。** 除非明确写「开始时…」「结束时…」，否则场景一开始就在动作中。
- **携带状态跨镜保留**：湿发、伤口、手持物、服装变化，要逐镜写出来，不要指望模型记得。

## 八、音频驱动

当音乐锁定动作时：

- 提示词正文**只写现场音**（环境声、动作音效、对白）。
- 配乐在后期叠加。
- 建立节拍映射：哪一拍对应哪个动作节点。

## 九、交付前的导演门禁

逐条检查：

1. 每镜能用一句可拍事实说清命题。
2. 机位来自观看关系，不是先选术语。
3. 构图持续保留固定参照，并为变化方向预留空间。
4. 视线有明确入口、唯一落点和自然出口。
5. 摄影机由动作或信息变化触发，并停在可见结果上。
6. 删掉字幕后，产品/叙事证据仍成立。
7. **节奏预算加得上总时长。**
8. **读列审计通过**：没有连续三镜同景别同运动。
9. 相邻镜头交换顺序后含义会变（否则只是同一画面换角度）。
10. 高风险镜头已标注（反射、双胞胎、人群、复合运镜、门口几何）。
