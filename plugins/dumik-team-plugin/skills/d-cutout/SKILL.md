# DUMIK 工业级极速精抠（d-cutout）

本 skill 专职**纯白 / 纯黑 / 纯色棚拍底图的工业级无损本地抠图**（3D 金属立体字、扁六边形徽章、认证标、ICON、白底产品、摆件选样、透明玻璃水晶、带接触软投影商品），**单张 2K 图 < 0.6 秒、零费用、边缘像素级锐利**，彻底取代慢速易糊边的 AI 抠图或手工反复写临时脚本试错。

> **与 `d-image-runner` 的清晰分工**：
> - 白底 / 黑底 / 纯色棚拍图（徽章、立体字、白底产品、透明玻璃、带软投影小件）→ **一律走本 skill `d-cutout`**（纯本地算法，无需付费授权）；
> - 复杂实景背景（生活场景、人物发丝、杂乱桌面）→ 脚本自动返回 `NEEDS_AI_MATTING`，再按授权交 `d-image-runner` RunningHub 高精抠图工作流。

## 参考文件

详细模式决策树、孔洞防误伤原理与参数速查见 `references/cutout-guide.md`（或运行 `scripts/compile_reference_pack.ps1 -Skill d-cutout -Mode solid`）。本 skill 为纯本地零费用工具，**严禁私自调用付费生图接口**。

## 极速三步闭环（从原来的 5 轮试错压成 1 次执行 + 1 次眼检）

### Step 1：按画面材质一键出透明底 + 双底验收板

直接调用 `scripts/cutout.py`（默认输出同目录 `<原图名>_透明底.png`，**验收预览板一律落 `%TEMP%\dumik-runs\`，严禁落入项目目录**）：

```powershell
python "<插件根目录>\skills\d-cutout\scripts\cutout.py" ^
  "<目标图片绝对路径>" ^
  --mode auto ^
  --preview "$env:TEMP\dumik-runs\cutout_verify.png"
```

按材质选 `--mode`：
- `--mode auto`（默认）：自动检测四边背景均匀度，纯色底秒走 `solid`；复杂实景图直接报 `NEEDS_AI_MATTING` 防误抠。
- `--mode solid`：3D 立体字、金属徽章、白底产品、高反光银/白主体（自动悬崖孔洞检测 + 保护金属高光不抠穿 + 2px 去白边反混合）。
  - 实心无镂空物体（如单杯、圆章）可加 `--no-holes` 更稳更快（~0.25s）。
- `--mode glass`：纯白/纯黑底透明玻璃杯、光学石英水晶、冰块、磨砂玻璃柱（物理还原真实半透明 Alpha 与折射色）。
- `--mode shadow`：白底商品/摆件需要保留自然底部柔和接触阴影时使用（阴影自动转半透纯暗影，贴任意浅/中色海报直接融合）。
- 设计师要在 PS 微调蒙版时加 **`--psd`**，同步写出 2 层可编辑 RGBA `.psd`（隐藏「原图备份」+ 可见去边「抠图主体」）。
- 批量处理整目录直接传文件夹路径（内置 4 线程并发）。

### Step 2：1 次 `read_file` 双底极速终检

立即用 `read_file` 查看 `--preview` 生成的双底对比验收板（左：深炭灰 `#1E2126` 查白边与漏抠孔洞；右：浅暖棋盘格查暗边与高光完整性），逐项确认：
1. **外轮廓零白边**：深炭灰底上边缘丝滑无白色锯齿环；
2. **高光 0 抠穿**：右侧棋盘格上银白/奶白金属高光面完好无破洞；
3. **封闭孔洞全抠透**：文字（如 `钛/健/安/选/A/P/R`）或镂空把手内孔全部透出深炭灰底色。

### Step 3：零代码微调（仅在 Step 2 发现局部瑕疵时）与清场交付

极少数极端窄缝漏洞或超亮贴边高光误伤，**严禁另写临时脚本**，直接原地加参数 0.4 秒重跑覆写：
- 漏抠某封闭白洞：`--punch x,y`（支持多个坐标如 `--punch 450,620 --punch 710,1160`）
- 误抠某贴边高光：`--keep x,y`
- 边缘偏松/偏紧：`--tightness 0.3`（更紧去边）或 `--tightness -0.3`（更松保细丝）
- 保持原图完整画布不裁切：`--no-crop`（默认自动紧凑裁切并留 `--pad 60` 透明边距）

验收通过后**立即删除 `%TEMP%\dumik-runs\cutout_verify.png`**，回复用户给出 `<原图名>_透明底.png`（及可选 `.psd`）的点击直达 `file:///` 链接与一行验收结果。
