# DUMIK 极速精抠手册（d-cutout）

## 一、为什么白底 3D 金属/立体字绝不能乱用普通阈值或 AI 抠图

1. **普通亮度阈值死穴**：高反光金属/纯钛/陶瓷高光区同样会冲到 `RGB(252~255)`，全局阈值必把字芯高光抠成筛子。
2. **通用 AI 抠图（rembg/在线去底）死穴**：AI 模型会重新缩放推理导致 2K 边缘发糊、啃掉细小金属斜角、还经常把半透明玻璃或紧凑汉字内孔糊死。
3. **`d-cutout` 核心工业方案**：
   - **4 连通边界洪水填充**：从四边纯色背景安全逼近，绝不越过外轮廓墙渗入内部高光；
   - **局部 ROI 向量化「悬崖孔洞检测器」**：对每个内部近背景连通域只切局部包围框计算（比全图膨胀提速 85×）：
     - 真正背景孔洞紧贴暗色/有色金属外墙，2px 外环亮度跳变呈现**悬崖特征（`ring_diff_luma >= 122` 且 `wall_ratio >= 0.52`）**；
     - 金属高光被柔和浅银渐变包围，`ring_diff_luma` 通常 `< 110`，被 100% 保护不抠穿；
     - 同步补检被极暗轮廓墙 360° 围死的微灰小孔（如窄笔画夹角）；
   - **Sobel 梯度阻断式凹角清理**：清理窄缝内柔和环境光遮蔽灰影（AO），遇到强倒角梯度墙立即刹车；
   - **2px 覆盖率抗锯齿 + 邻域实心外推反混合（Color Decontamination）**：解算边缘覆盖率并对半透明像素做背景色剥离，贴深炭灰 `#1E2126` / 纯黑海报零白边。

## 二、模式速查与参数手册

| 场景 | 推荐命令参数 | 说明 |
| --- | --- | --- |
| 3D 立体字 / 镂空图标 / 带把手杯壶 | `--mode solid`（或 `auto`） | 默认开启悬崖孔洞自动检测 + 凹角清灰 + 60px 透明边距裁切 |
| 实心扁六边形徽章 / 无镂空小件 | `--mode solid --no-holes` | 跳过内部孔洞检测，0.25s 极速出图，绝不误伤徽章亮面 |
| 透明玻璃杯 / 光学水晶 / 冰块 | `--mode glass` | 物理减色/加色 Alpha 解算，保留透明折射层次 |
| 需自带柔和底部接触影的白底商品 | `--mode shadow` | 主体 100% 实心精抠 + 底部自然灰影转半透纯暗影 |
| 设计师需进 PS 微调 | 追加 `--psd` | 同步导出 2 层 RGBA `.psd`（隐藏原图备份 + 可见去边主体） |
| 保持原图 2K 原始画布对齐排版 | 追加 `--no-crop` | 不做紧凑裁切，直接保留原图分辨率与坐标 |
| 整文件夹批量精抠 | 直接传文件夹路径 `--workers 4` | 自动跳过已带 `_透明底` 的文件，多核并发 |

## 三、极端场景逃生舱（0 写临时脚本）

- **个别窄缝微洞未自动抠出**：从预览板定位像素坐标，追加 `--punch x,y`（原图坐标系；若开启了裁切，可先 `--no-crop` 或直接读取 JSON 返回的 `crop_box` 偏移换算）。
- **某块紧贴黑线的超亮反光被误判为洞**：追加 `--keep x,y` 锁定保护。
- **边缘仍带极淡 1px 浅边**：追加 `--tightness 0.25` ~ `0.5`。
- **细微发丝/极浅外边缘被吃掉一点**：追加 `--tightness -0.25` ~ `-0.5`。

## 四、命名与零垃圾铁律

- 默认输出名：`<原图名>_透明底.png`（开启 `--psd` 时同目录生成 `<原图名>_透明底.psd`），严格中文命名。
- 验收预览板必须写到 `%TEMP%\dumik-runs\`，眼检验收后立即删除，项目目录内严禁残留调试图与 `.json`。
