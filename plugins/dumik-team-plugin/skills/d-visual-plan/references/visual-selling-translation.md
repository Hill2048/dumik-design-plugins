# 产品视觉与卖点纯画面翻译规范

从电商传达的第一性原则出发：**生图模型拍不出形容词，只能拍出「实体对象 + 光学质感 + 物理动作瞬态 + 参照物对比 + 干净负空间」**。且团队规范已明确：**AI 只出纯无字底图，所有排版与文字后期在 PS 人工完成**。

本规范规定 `d-visual-plan` 在拆解飞书画布或整理卖点写入 `project.md` 时必须完成的四层翻译动作。

---

## 一、过「买家下单三道坎」去重排主次

运营给的画布常把同一卖点在不同屏幕反复写成近似句子。拆解入 `project.md` 时，先按真实决策顺序收敛去重，绝不连出多屏同质化画面：

1. **第一眼爽点（凭什么停下）**：肉眼一秒看得懂的使用收益或形态差异（例：宽底平煎 4 颗蛋不挤、深勺头一勺兜起大云吞不漏汤、叠叠锅煎盖倒扣秒变锅盖省空间）。
2. **信任硬证据（凭什么信你值这个价）**：买家最怀疑“是不是智商税”的地方，必须拆给近距离物理实证（例：钢铲贴底铲煎蛋、油珠高接触角滚落、微距宽倒角无接缝、三层复合金属截面结构）。若画布连排重复概念，拆成「一屏中景使用爽点 + 一屏微距物理证据」打配合。
3. **日常顾虑兜底（买回去好不好用）**：单手轻便端取、洗碗机高压水洗、不挑明火电磁炉等。

## 二、抽象卖点转 4 类物理画面证据（禁止直抄文案词）

任何要生图的屏幕进入 `project.md` 前，必须**先提炼「这一屏核心到底要表达/证明什么」（逐项对照运营原图与右侧参考，严禁多图强揉成 1 张、严禁只顾套视觉氛围却丢了物理论证动作——如表达手柄坚固必须装重满载冰饮用力单手提，表达静置抗菌不能画刚刚倒新奶）**；然后再交视觉设定决定“长什么样”。禁止保留“高品质、更健康、大容量、做工好”等虚词，必须落地为下表 4 类之一（可匹配 `assets/detail-page-prompt-packs/` 视觉证据方向）：

| 卖点类型 | 严禁的字面抄法 | 第一性物理画面翻译 | 证据分类 |
| --- | --- | --- | --- |
| **尺寸 / 容量 / 形态** | “49mm 加宽加深大容量” | **熟悉参照物 + 满载瞬态**：用常见食物或日常动作作视觉标尺（整颗大馄饨与浓汤齐沿不洒、多块牛排或四颗荷包蛋同锅舒展铺开） | `场景与动作证明` |
| **材质 / 工艺 / 触感** | “100%纯钛、一体成型、圆润” | **光学微距 + 接触瞬态**：明确写出光打在表面的结果（掠射光勾出勺沿连续柔和宽反射带、手柄连接处金属平滑一体过渡无焊点） | `材质与结构微距` |
| **性能 / 防护 / 痛点** | “0氟不粘、耐磨、不糊底” | **极限动作测试 / 同框并置对比**：钢铲硬铲脆边荷包蛋、浓稠粥浆顺滑推起锅底净亮、左右同机位同等光照对比常规粘底与本品洁净对比 | `对比证明` |
| **检测报告 / 参数 / 售后** | 让生图模型硬画证书与毫米数字标尺 | **剥离生图队列**：直接标为 `pure layout`（状态：`无需生图（后期排版）`），后期用白底正侧视图与真实报告排 PS 长图 | `纯后期排版` |

### 概念装置表达 vs 实景故事表达分流（禁强行混场景）

- **概念美学棚拍轨**：材料金字塔阶梯对比（纯钛 vs 不锈钢）、双层剖面结构机制、纯材质微观反光、品牌超级符号等**抽象分级/技术证明屏**，必须走**同色系极简建筑装置/概念摄影棚拍**（严格继承 `design.md` 色彩与光学公式），**严禁把阶梯金字塔等概念道具硬塞进客厅/餐桌实景或往阶梯上倒水**，制造违和感。
- **实景生活故事轨**：使用痛点、口感保鲜、单手轻量、防漏开合、日常易洗等**人货生活屏**，才调取**场景身份卡 + 人物身份卡**，每屏围绕一个“真实晨光生活小故事”构图（交代前因后果道具链与真实人物微动作）。

## 三、全案视觉母体与单屏动作彻底解耦

详情页不散、不像拼凑图的核心在于**「90%视觉母体固定 × 10%单屏动作切换」**：

- **全案不变量（第 0 批里程碑确认后锁死进 `design.md`）**：
  1. **材质光学公式**：写定主材质与副材质在光下的物理反射区间（例：纯钛呈低饱和冷银灰缎面漫反射，忌镀铬碎反光与惨白高光）。
  2. **统一空间与光影母版**：全套共用一套色温、主光角度、光比和台面材质家族；凡涉及实景多屏跨视角出场，优先用 `16:9` **场景身份卡（左放品落位特写 + 右完整人景空间全景）** 先锁世界观，且严禁拿生成候选反复串联垫图（防止越垫越红发闷）。
  3. **超级符号（视觉锤）**：首屏 KV 与核心主图共享 1 个强记忆符号，不每屏乱变特效。
- **单屏唯一变量（写在 `project.md` 各屏行内）**：
  - 每屏全盘继承上述母体，只切换**物理动作故事与景别距离**。
  - 上下相邻分屏强制**景别呼吸交替**（中景使用场景 → 掠射材质特写 → 同机位功能对比），避免连续多屏同一俯拍角度引起视觉疲劳。

## 四、纯无字底图禁令 + 负空间预留 + 9:16 一镜贯通构图

1. **全画面绝对净底**：除产品本体实拍原图上真实存在的原生丝印/激光刻字外，**严禁生成任何标题文字、利益点气泡、价格角标、数字标尺线、指示引线或放大圆框**。需要局部细节放大标注的，AI 只负责出一张高清纯微距图，由用户在 PS 中自行拉线框图。
2. **按画布文案密度自然留白（严禁诱发横向拼条）**：
   - 保留 `project.md` 中的运营原主副标题供字数密度评估与 PS 直接复制；**写词前若该屏附有 `素材/飞书画布/<编号>_参考.*`，先读图一眼确认构图与底色明暗再下笔，绝不把竞品参考图直接作为 API `@图N` 垫图**。
   - **禁止把「顶部 28% / 中段 52% / 底部 20%」「三段式分栏」写进最终生图 Prompt**：生图模型会把分段百分比字面理解成上下多条生硬的横向白条分割线。必须改为**「一镜到底连贯空间透视」**——通过挑高连贯的浅调墙光影自然向上延展、平滑连续的桌面/地面向底边延伸，让主体稳落中焦偏下（兼顾向下切 `3:4` 主图与居中取 `1:1` 不断边），自然给出 PS 压字负空间。

## 五、纵向序列导演法则（静态详情页专用，无运镜无时长）

整套竖版详情长图本质上是一条连续向下滑动的「定格分镜序列」。把视频导演线里经过验证的三条静帧可用法则提纯接入详情页策划与写词（严禁混入动态运镜词、秒数或口播表演词）：

1. **纵向「机位景别列」单调性审计与双对比切屏**：
   - 把 `project.md` 中第 1 批、第 2 批全部非排版分屏的「机位景别」单拎成一列从上往下读，**严禁连续三屏共用同一景别且同一机位角度**（杜绝连着五屏都是 `45°` 微俯摆台）。
   - 相邻分屏切换必须同时拉开尺度与观看立场（如：`微俯3/4·中景瞬态` → `掠射平视·微距特写` → `正俯90°·满载对比`），拆解脚本已按垂直顺序自动轮转配平 `机位景别` 列。
2. **多参考图三级保真度标定**：
   - 在 `制作/<编号_名称>/prompt.md` 同时绑定多张参考图时，必须逐张写死保真边界：
     - **`[结构锁死]`**（对应 `@图1` 产品白底图）：完整锁死外轮廓比例、关键部件数量、接口位置、材质固有色与原生丝印；严禁借用白底图的白背景与棚拍平光。
     - **`[属性迁移]`**（对应 `@图2` 场景身份卡 / 里程碑母版）：**仅迁移空间建筑关系、主光方向、色温光比、材质反射气质与台面家具家族，严禁照搬原图的窄构图或原图多余水杯**。
     - **`[人物身份与穿搭锁]`**（对应 `@图3` 人物身份卡，若有）：锁定最左侧清晰五官与穿搭，**绝对忽略全身小图脸部的纯红遮挡块**。
     - **`[动作引导]`**（对应示意草图，若有）：仅参考物理交互动作与大致方位关系，不借画质与竞品外形。
3. **「一图讲一个小故事」+ 表情视线设计 + 8大构图母型防撞车配平**：
   - 拒绝无来源轮廓光、呆板展厅全框（每张都退远框完整张沙发圆桌）和干瘪摆拍两件死物；每张画面都应能说出一句“刚刚发生了什么”的生活或实验小故事（如：玻璃奶壶刚注完鲜牛奶留于远景衬托丝滑纯净、刚翻完两页书摘下的眼镜旁一杯热茶轻袅薄雾）。
   - **人物表情与视线必须刻意设计**：只要有人物脸部入画，必须明写**微表情与精确视线落点**（如低眸专注看杯面热气、或刻意设计过的清冷疏离杂志感——微抬下颌越过窗光斜影沉静远望、眉眼唇肌放松带克制呼吸感），禁止漫无目的的放空发呆。
   - **按屏分配「8大构图母型」且桌上配饰群组严格 ≤ 3 件**（母型全表见 [相机与构图母型库](../../d-image-director/references/camera-language.md#高阶商业构图母型库选型即写死几何结构禁止杂志感高级构图虚词)）：纵向排屏时必须在以下母型间轮转，相邻分屏严禁撞车——①单侧建筑/人影前景偷窥框；②半桌/半椅切边 + 走廊空间纵深；③对角光带切割与明暗楔形；④桌面 L/Z 型导视线（一物斜指杯底）；⑤去脸局部触碰/悬停开盖对位/屈膝作支点；⑥托特包或书拱 V 型夹框；⑦概念斜倚平衡/百叶窗条纹背板；⑧`90°` 上帝俯视大色块围合。
   - **宁缺毋滥道具铁律**：桌面除去主产品，次要配饰群组 ≤ 3 组（例如仅 `1本精装书 + 1盏台灯 + 1副眼镜`），用干净台面与连续光影墙面留出高级呼吸感，绝不堆叠杂物。
