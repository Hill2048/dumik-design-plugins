# 飞书画布自动拆解规范

当运营通过飞书文档或飞书白板画布交付产品策划时，使用 `skills/d-visual-plan/scripts/parse_feishu_canvas.py`（或直接通过 `d-init` 的 `init_dumik_project.py` 一键调用）自动拆解并直接写入或增量更新项目根目录 `project.md`。**默认不在项目目录写出 `canvas-manifest.json` 或独立 `拆解清单.md`，做到零本地运行垃圾。**

## 输入、权限回退与增量同步

1. 支持飞书 Wiki 链接（`/wiki/<node_token>`）、Docx 链接、带 `blockToken=` 的画布直链或 `--whiteboard-token`。
2. 优先使用 `--as user`；个人登录未就绪时自动回退 `--as bot`；均无权限时明确提示运行 `lark-cli auth login`。
3. 附加 `--download-assets` 时，由 `scripts/render_feishu_board.py` 按分区（主图区 / 入口区 / 详情区）用纯 Python Pillow 在本地还原飞书画布完整排布并按卡片/行区自动裁切：产出 `<项目根>/素材/飞书画布/*区总览.png`、`<编号>_画布原图.png`、带侧边参考的 `<编号>_整行.png`，以及高清原尺寸 `<编号>_参考1..N.<ext>` 并直接嵌图写入 `project.md`；未挂文案的纯竞品图与纯拍摄角度参考不进入队列。
4. 传入 `--sync` 时，从已有 `project.md` 头部自动识别 `- 飞书源：`，重拉飞书并保留表中已有 `已锁定`、`已定稿`、`候选已出`、`提示词就绪` 状态、`当前出图` 缩略图及对应参考路径。

## 原标题留存 + 画布参考图视觉阅读与 API 隔离铁律

1. **原主副标题与批注完整留存**：`project.md` 内单设一列原文保留运营主副标题与便签批注——一方面供 Agent 在 `d-image-director` 写词时直观判断字数密度与负空间底色需求，另一方面方便用户在 PS 排字时直接复制，无需翻回飞书；但**严禁把这些文案写入生图提示词让 AI 画出来**。
2. **画布参考图按需睁眼读图**：`素材/飞书画布/<编号>_画布原图.*` 与 `<编号>_参考1..N.*` 仅以相对路径 `<img src="素材/飞书画布/..." width="110">` 嵌在 `project.md`（纯文本几十字节，零上下文膨胀）；初次拆解分析无文字框的纯截图屏时，以及动笔写某屏 `prompt.md` 前，Agent 必须用真实读图工具看一眼该屏画布原图/整行裁图与参考图，秒懂构图斜率、对比张力、叠改文字与明暗落点。
3. **画布参考截图与生图 API 垫图物理隔离**：画布参考图多为竞品截图或带字参考，**绝对禁止作为 `@图N` 传入 `generate_batch_images.py`**（仅允许用户显式要求按草图/线稿走结构参考时例外）。生图 API 垫图只收 `设定集/白底图/` 与 `设定集/里程碑/` 的自有干净图，其余视觉意图全部通过文字镜头指令转译实现。

## 多轮与多画布选择规则（无 `blockToken` 时）

1. **跳过纯视频画布**：章节标题明确为纯视频（如 `主图视频策划` 且不含 `详情`）自动跳过，不混入静态清单。
2. **提取里程碑画布**：标题或内容含 `里程碑` / `产品身份卡` / `首屏KV` / `超级符号` 的画布，全部提取视觉里程碑槽位。
3. **主策划画布 vs 修改补丁画布**：其余静态画布中优先取节点最全的 `主图详情策划` 作为底表；位于文档更上方且节点精简或含 `修改 / 返修 / 调整` 的画布归为 `最新修改轮补丁` 置顶提示。
4. **双方案隔离**：同画布左右并排多列详情方案时，主列入账，备用列只在「待拍板提醒」标明不混序。

## 三大交付物与视觉表达翻译映射

| 标准交付物 | 画布常见标法与形态 | 拆解与翻译处理 |
| --- | --- | --- |
| **主图（3:4）** | `主图` / `750主图` 旁横向大图、空框或 `section` 线框 | 编号 `M01..Mk`；优先标定哪些由第 1 批 `9:16` 同源母片裁切派生 |
| **详情页（790 x n）** | `详情` 路标或纵向连续分屏栈（内嵌小图归并进主屏） | 编号 `S01..Sn`；按 [视觉与卖点纯画面翻译规范](visual-selling-translation.md) 标定物理证据、PS 留白位，并自动把纯报告/纯参数屏标为 `无需生图（后期排版）` |
| **入口图 / SKU（1:1）** | `800主图` / `车图` / `车图角度` / `sku` 旁方图方框 | 编号 `E01..Em`，排第三批，无法由 `9:16` 裁切复用再独立出无字底图 |

- 同时兼容 `sticky_note`、`text_shape`、`composite_shape`、`section` 线框与 `必渲①~N` 结构特写；自动过滤周围无任何可编辑文案/便签的纯竞品拼图。

## 固定交付顺序与默认 9:16 无字母版

1. **第 0 批**：视觉里程碑设定（定调后锁入 `design.md` 与 `设定集/里程碑/`）。
2. **第 1 批（最优先）**：详情页中与 `3:4` 主图共用画面或共用 `必渲` 特写的核心分屏（默认 `9:16` 三段式无字构图，兼顾 `790xn` / `3:4` / `1:1`）。
3. **第 2 批**：详情其余分屏（纯报告/参数屏直接跳过生图）。
4. **第 3 批**：无法裁切的独立 `1:1` 入口/SKU。
- 拆解完毕停在 `project.md` 待用户确认；后续按确认内容交 `d-image-director` 编写纯无字 `prompt.md`，再等明确生图口令交 `d-project-pipeline` + `d-image-runner` 执行。
