# 一致性验收清单

## 用法

1. 标明 `@图A` = 原图真源，`@图B` = 生成图（编号以实际输入为准）。
2. 逐项只选：一致 / 不一致 / 无法判断。
3. 汇总总判与交接建议。

## 分项标准

| 项 | 一致 | 不一致 | 无法判断 |
| --- | --- | --- | --- |
| 外形比例与轮廓 | 剪影与长宽关系同族，无拉长压扁 | 明显变形、缺角、圆角被改 | 强透视/裁切看不到完整外轮廓 |
| 接口数量与位置 | 孔位/插口数量与相对布局可对上 | 多孔、少孔、明显移位 | 背面或阴影遮住接口 |
| 按键 / 旋钮 | 数量、排布、大致形状一致 | 增减或形态换成另一套控件 | 分辨率不足或被手/标签挡住 |
| 材质倾向 | 同为金属/塑胶/木等大类，反射行为不矛盾 | 金属变哑光塑料等类级错误 | 过曝或风格滤镜掩盖材质线索 |
| Logo / 丝印区 | 占位区域大致同侧同高 | 标移到错误面/消失/乱字充占位 | 原图本身无清晰标且生成图仅有模糊斑 |
| 颜色固有色 | 色相家族一致（允许明暗差） | 明显换色（银变金、原木变黑檀等） | 色铸极端或单通道预览 |
