# 美食本身深度精析：烹饪物理 × 味觉可视化 × 三层料理结构（v0.6.0）

> 专门补齐“只讲摄影构图、不讲食物本身烹饪逻辑”的短板。写任何熟食/料理提示词前，必须先像**黑珍珠/米其林主厨 + 商业美食造型师**一样拆解食物本身的**火候化学、口感物理信号与风味结构**，再落到画面描述。

## 一、六大口感的“味觉可视化”物理信号（一眼看出好不好吃）

严禁使用空洞形容词（如“美味、诱人、色香味俱全”），必须把**口感翻译成肉眼可见的微观物理特征**：

| 想表达的口感 | 肉眼可见的物理信号（必须精准写入提示词） | 常见 AI 翻车反面教材 |
| --- | --- | --- |
| **糯 / 软烂**<br>（东坡肉、牛腩、猪蹄） | **重力软塌微弧 + 压痕 + 纤维微裂**：稻草绳轻轻勒进酥软猪皮 1~2mm 的真实压痕；肉块在自身重力下微微外鼓；瘦肉纤维之间隐约裂开渗出晶莹肉汁；胶原皮层呈半透微颤光泽 | 方块僵硬如木块、边角死直无重力软态 |
| **酥 / 脆**<br>（可颂、锅巴、生煎底、脆皮烧肉） | **起酥蜂窝薄壁 + 焦脆气泡 + 自然剥落碎屑**：千层酥皮切面露大小不一的不规则气孔壁、外层薄如蝉翼微微翘起；砂锅锅巴或生煎底见不规则金黄微焦气泡孔；盘边极克制留 2~3 粒真实酥皮碎 | 表面平滑像软面包、锅巴像死硬黄饼干 |
| **嫩 / 滑 / 弹**<br>（豆腐、清蒸鱼、虾仁、溏心蛋） | **表面张力圆润高光曲面 + 蒜瓣/微孔肌理**：嫩豆腐切口见极细微气孔且边角微颤；清蒸鱼肉刚好熟透呈蒜瓣状自然微裂；温泉蛋蛋白呈半凝固玉白、蛋黄呈将流未流的浓稠橘金膏状 | 豆腐像光滑白橡皮、鱼肉干柴发白、蛋黄全熟粉黄 |
| **鲜 / 滚烫 / 刚出锅**<br>（热汤、清蒸、爆炒） | **热油微卷葱丝 + 极细油珠聚散 + 刚停沸微泡**：葱丝/蒜苗遇热油微微打卷泛清冽油光；汤面油珠大小不一自然聚散；酱汁与碗壁交界处留极细湿润挂壁痕与刚收火的极微细泡 | 死板生硬大葱段、糊满全图的假白浓烟 |
| **香 / 镬气 / 美拉德**<br>（煎牛排、爆炒牛肉、炙烤） | **三段式火候色阶（Maillard Gradient）**：煎烤表面从边缘微焦黑褐 → 主体深琥珀焦褐 → 切面粉嫩多汁（或外焦里嫩），且表面干爽裹极薄油膜绝不泡在脏油里 | 通体发黑焦糊、或表面死灰无焦香反光 |
| **麻 / 辣 / 浓烈**<br>（麻婆豆腐、水煮鱼、红油面） | **油水清晰分层 + 透亮暗宝石红油**：底层是深棕焦香豆瓣肉末、表层浮着清亮透底的暗宝石红辣油，绝不搅成浑浊发黑的泥浆；点缀少量青红花椒粒与细微红椒籽 | 发黑浑浊脏油、荧光橘红假辣油 |

## 二、顶级料理摆盘的“三层风味建筑结构”（为什么高级菜不显乱）

任何一道成品料理在器皿中都必须严格拆成 **3 层结构**，绝不混成一团：

1. **底层 · 托底画布（Base / Foundation）**：
   - 如极浅一层清亮蒸鱼豉油、一抹镜面红酒汁、八分满清亮牛骨汤、蓬松粒粒分明的丝苗米饭；
   - **铁律**：托底永远只起承托和反光作用，**绝不淹没主角**（酱汁厚度 ≤ 食材高度的 1/5）。
2. **中层 · 主构体量与刀工（Hero Mass & Knife Work）**：
   - 必须交代**刀工形态、切面朝向与堆叠几何**：
     - 切片类（牛排、叉烧、腊肠）：斜切 45° 瓦片叠扇，切面朝向镜头露出最诱人的粉红芯或肥瘦纹；
     - 块状类（东坡肉、麻婆豆腐）：方正厚切立挺，或棱角错落堆高出立体纵深；
     - 丝条类（手工面、意面）：顺汤纹优雅梳折成半月形，或卷高成饱满鸟巢状；
     - 烘焙类（可颂、巴斯克）：斜剖 30° 或轻挖一角，强制露出内部蜂窝气孔或流心截面。
3. **顶层 · 极细收口点睛（Micro-Garnish / Finish）**：
   - 只选 **1~2 种呼应菜品真实味型的极细点睛**（如三丝葱姜红椒、三五粒片状海盐结晶、一撮翠绿蒜苗碎、两三粒花椒、几滴翠绿葱油/罗勒油珠），**总量不超过主菜可见面积的 10%**，绝不抓一把大葱花香菜把主菜埋掉！

## 三、8 大烹饪技法专属物理速查表（写词直接对号入座）

| 烹饪技法 | 必写食物本身物理核心 | 绝对禁区 |
| --- | --- | --- |
| **1. 焖 / 炖 / 红烧** | 半透明镜面焦糖薄芡、胶原微弹毛孔、重力微鼓与绳勒压痕、五层肥瘦切面 | 黑糊厚酱、死硬棱角、干哑无光泽 |
| **2. 蒸 / 白灼** | 澄面玉润半透褶皱透馅、鱼肉蒜瓣微裂、极浅清透豉油、热油微卷极细三丝 | 死白厚皮、鱼皮干裂发灰、浓稠黑酱 |
| **3. 煎 / 炙烤** | 三段美拉德焦化色阶、焦脆微壳×粉嫩多汁切面、肉汁微渗、片状海盐结晶 | 死黑焦炭、全熟发灰干柴、油腻血水 |
| **4. 爆炒 / 镬气** | 食材边缘微焦镬气斑、极薄亮油裹身干爽不积油、配菜脆嫩带自然微卷 | 盘底积一滩脏油、菜叶发黄软烂、塞满整盘 |
| **5. 汤 / 煮 / 面** | 汤色清亮或浓白乳化分明、大小不一自然浮油珠、顺纹梳折面条、肉菜分区露顶 | 面条乱缠坨状、汤面浑浊脏沫、配料溢碗 |
| **6. 烘焙 / 起酥** | 不规则千层蜂窝气孔壁、金棕美拉德焦脆薄皮微微剥落、温热流心垂坠张力 | 实心面包感、死板完美对称、表面发白无焦度 |
| **7. 冷盘 / 轻食** | 利落锐利刀工切面、乳化油醋汁微光、低饱和自然色块分层堆叠、微润露感 | 沙拉酱糊满全碗、食材蔫软发暗 |
| **8. 糖水 / 甜品** | 琥珀胶质悬浮光学折射、糖浆绸带拉丝含细微悬浮气泡、丝绒微孔泡沫 | 稀汤寡水无胶质感、荧光假色素 |
