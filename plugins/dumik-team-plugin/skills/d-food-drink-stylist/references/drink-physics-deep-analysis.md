# 饮品本体物理与顶构造型手册（v0.9.0 · 纯本体版）

> 聚焦饮品本身的液体物理、冰晶形态、奶盖微孔与顶构造型；**不涉及场景光源、机位与台面**（一律交还 `design.md` 与 `d-image-director`）。配图参考见 `assets/moodboards/01_高定饮品造型精选.jpg`。

## 一、六大饮品口感的微观物理信号

| 口感 | 必须写入的饮品本体物理细节 | 常见翻车 |
| --- | --- | --- |
| **冰冽** | 手凿大冰块带**微融圆角、内部自然冰裂纹与微雾冰芯**，顶出液面 8~15mm 挂湿润水膜；透明杯外壁带大小不一自然冷凝微水珠及 1~2 道滑落水痕（不透明保温杯外壁必须干爽无水珠） | 棱角死硬的 CG 透明塑料方块 |
| **丝绒厚乳** | 高出杯口 6~8mm 的自然微旋奶盖峰，表面见**极细密绵密微泡沫气孔**；奶液与浓缩/茶底交界呈未搅匀慢速云雾涡流；杯内壁高出液面 2~3mm 留微稠挂壁弯月痕 | 光滑塑料膏、死平油漆面、机械对称拉花 |
| **激爽气泡** | 紧贴冰块棱面与内壁附着成串大小不一的晶莹微气泡，液面边缘留极细刚破裂的微沫环 | 死水无泡、廉价肥皂大泡 |
| **清透茶韵** | 无铁纯无色薄壁光学玻璃杯（零青绿切边），清透深琥珀/红宝石/浅香槟茶汤通透见底，内壁保留极细湿润弯月液痕 | 普通玻璃青绿脏边、浑浊茶水 |
| **炙热香料** | 杯口正上方极淡半透纤细热气丝；炙烤脱水半透琥珀薄橙片（露囊瓣与微脆焦边）；整根天然纵裂肉桂棒或油润黑香草荚半浸微润 | 糊脸假白浓烟、塑料厚橙片平贴 |
| **不透明杯锁** | **纯钛/金属/陶瓷杯 100% 锁定实心不透明杯壁**：严禁写杯身纵向分层或透视果片，所有层次仅刻画杯口液面与顶出杯口的雕塑冰/云顶奶盖/横架香草荚或炙烤无花果 | 金属杯被 AI 强行画透明 |

## 二、高定饮品三层结构

1. **底层基底**：清透茶汤 / 冰浓缩 / 厚乳基底盛八分满，留出杯口内壁湿润弯月痕；
2. **中层动态**：手凿大冰柱、未搅匀云雾涡流或附壁微气泡链；
3. **顶层雕塑点睛**：微旋云顶奶盖 + 极克制坚果/冻干果碎、或冰顶斜倚半颗炙烤焦糖无花果、或杯沿横架整根黑香草荚、或单朵可食用紫罗兰（严禁堆满半杯切块水果与大把薄荷）。
