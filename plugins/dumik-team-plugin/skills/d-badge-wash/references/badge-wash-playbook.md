# 徽章与小件清洗重构实操手册

## 一、Step 1 纯色脱壳提示词模板（2D 平面矢量真源）

> 适用条件：原图带有旧金属拉丝、渐变、阴影、3D 倒角或杂色背景。若原图已是干净黑白/纯色矢量线稿，直接跳过 Step 1。

- 规格：`Banana 2.1` · `1:1`（或匹配原图比例）· `2K` · `x2`
- 参考图：仅传 `@图1`（原图）
- 提示词骨架（按实际文字与图形替换占位符）：
  ```text
  将@图1<徽章/图标形态>100%忠实转换为极净锐利的纯色2D平面矢量设计图，置于纯白背景（#FFFFFF）正中，正正面平视完全对称。严格保持@图1全部原始构图、内外比例与细节完全不变：<逐字列出全部外环/内区中英文白名单及精确位置>；<准确描述核心图形线条结构>。彻底去除@图1所有拉丝金属纹理、渐变、倒角、反光、高光与阴影，只用极简纯平实色色块表达层次：<外框/外环纯平浅灰白 #EFEFEF 配清晰黑边与纯黑字，内底纯平纯黑 #111111，前景图标与文字纯平纯白 #FFFFFF>。纯扁平平面矢量插画风格，边缘锐利干净，严禁任何3D立体感、渐变、金属质感、阴影或杂点。
  ```

### Step 1 逐字逐笔验收清单（任一项不通过直接重抽，严禁带病进 Step 2）

| 核查项 | 合格标准 |
| --- | --- |
| 英文拼写与弧度 | 逐字母核对零漏字/错拼/粘连，弧线居中对称 |
| 中文笔画结构 | 逐字核对零缺笔/多笔/鬼画符，粗细一致 |
| 核心图形拓扑 | 线条断点、闭合与原图 100% 一致，无多余杂线 |
| 材质脱壳纯净度 | 100% 扁平实色，零渐变、零阴影、零旧拉丝残留 |
| 背景纯净度 | 纯白 `#FFFFFF` 无灰边无噪点 |

## 二、Step 2 3D Octane Render 重构提示词模板

- 规格：`Banana 2.1` · `1:1` · `2K` · `x2`（若文字极简且偏重复杂微光学，可并发对照 `即梦 5.5`）
- 参考图职责锁死（**严禁再传老原图！**）：
  - `@图1`：Step 1 验收通过的 **纯色平面图**（唯一几何、比例、图标与文字锁）
  - `@图2`：项目 **品牌标贴/主材质参考图**（只取金属抛光、镜面反差、倒角与底托工艺，不抄形状与品牌字）
  - `@图3`（可选）：项目 **已定稿概念母版**（如 `MS06`/`S06`，取配套烤漆/磨砂玻璃底盘材质与静奢光感）

### 常见底盘材质组合速查

| 方案 | 主体浮雕 / 外环材质 | 内盘底面材质 | 适用视觉语境 |
| --- | --- | --- | --- |
| **A 案（高对比腕表标牌，默认推荐）** | 对标品牌标贴的液态高光镜面金属（零拉丝、强镜面扫光、外沿可衬极薄冷银底托边） | 对标概念母版的零颗粒丝滑深色钢琴烤漆 / 哑光丝绒底，内环接缝带一线极克制暖光反光棱 | 静奢、高端、需要缩略图一眼看清中文字 |
| **B 案（通透玉脂发光感）** | 同上液态高光镜面金属 | 对标概念母版的半透柔雾磨砂玻璃 / 玉脂渐变底（带柔和内透微光） | 强通透、母婴/纯净/科技轻盈概念 |
| **C 案（极简哑光素瓷/冷钛风）** | 与产品本体同源的细腻哑光金属/冷银雪花钛 | 高级低反差柔雾素瓷/暖象牙纯漫反射底 | 强工业极简、同材质一体感 |

- 提示词骨架：
  ```text
  3D Octane Render 高定珠宝腕表级立体徽章渲染，正正面平视居中置于极净纯白背景（#FFFFFF，无杂物，纯白底方便抠图），100% 严格保持@图1纯色平面图的全部原始设计、比例与白名单文字（<再次逐字写明全部文字>）及核心图标完全不变。材质与风格100%继承@图2材质参考与@图3概念母版的视觉体系：<写清外环/前景浮雕/凹刻字的液态镜面或指定金属质感 + 倒角 + 托边工艺>；<写清内盘底面的烤漆/半透磨砂玻璃材质与内环微光反射线>。Octane Render 物理路径追踪，细腻柔光箱扫光与精致微倒角高光，彻底摒弃旧拉丝纹、做旧暗铜或粗糙颗粒感，严禁擅自新增任何额外文字或图形。
  ```

## 三、归档命名与防污染规范

- 分层归档目录：全案跨屏复用资产（品牌标贴、超级符号、章节通用过渡底）落 `设定集/品牌资产/`；**单屏专属认证标/数据标/ICON/展示件一律落对应屏 `制作/<编号_名称>/局部配件/`**（不增加 `project.md` 屏数，也不被 `--status` 或 Hook 计入候选图）。
- 文件命名（全中文 + 清晰阶段后缀）：
  - `<资产名>_原图.<ext>`
  - `<资产名>_纯色平面图.png`
  - `<资产名>_3D_Octane_01.png`（多版用 `_02.png`；确认后可改名或另存为 `<资产名>_定稿.png`）
- 若需把定稿徽章直接导入 DesignFlow 供后续参考或复盘，`placeOnCanvas: false` 入库并登记至项目 `design.md` 的「品牌与小件资产」栏。
