# 图片引用格式

图片、视频、分镜、测试与批量任务的自然语言提示词统一使用 `@图1`、`@图2` 等图片引用。角色说明、正文、约束、模板和脚本生成的提示词使用同一写法；视频与音频引用保持各自类型。

- 只统一引用的写法，保留原数字、对应文件和用途。对已有引用做格式转换时，不重新分配素材。实际提交清单与编号不一致时，先核对映射，不凭编号猜文件。
- `@图1` 对应本次实际提交的第一张图片，后续按图片输入顺序对应；不是聊天历史的累计附件编号。仅交付文字时，明确配套图片顺序。
- 角色说明只在最终提示词开头写一次。单图不强加角色行；正文需要点名时仍使用 `@图1`。
- `image2` 等模型别名、API 字段、命令参数、变量名、文件名和素材 ID 不是图片引用，不做文字替换。
- 平台若要求专用素材标记，只在执行适配层核实后映射，保持素材关系不变；不能声称普通文本标记已经完成平台素材绑定。
- 交付前核对全文编号与真实输入，不只检查角色行。不要用替换全部英文单词的方法迁移格式。
