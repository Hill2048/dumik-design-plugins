# DUMIK 任务状态合同

用于需要多轮追改、恢复、候选比较、批量执行或用户说“继续 / 再改”的任务。一次性只要一句提示词且不需要恢复时，可以不创建状态文件。

## 文件位置

```text
制作/图片/<任务名>/任务状态.md
制作/视频/<任务名>/任务状态.md
```

优先复用已明确任务的现有说明或运行记录；已有状态载体不再复制一份。已进入项目多轮制作且允许落盘时才使用上述文件；纯文字、不落盘或侧对话不强制建目录。状态跟随具体任务，不写入 `design.md`，不升级为项目标准。不同会话或任务不能共用一个项目级“当前任务”。

## 最小字段

```text
任务名：
route_id：image.prompt / image.execute / video.prompt / ...
mode：edit / brief / direction / hd / repair / strategy / execute
目标图或主素材：
@图1：文件路径 + 职责
@图2：文件路径 + 职责
其他素材：
输出比例：
交付类型：提示词 / 方案 / 实际生成 / 后处理
执行范围：用户要求的动作、数量、对象、是否已用完；没有则写未授权
部件映射：用户称呼 -> 画面中具体部件（如“100%的四边形”是承载文字的铭牌，不是文字笔画）
已确认保持：
本轮最新变化：
明确不采用：
最后完整提示词：
更新时间：
```

## 更新规则

- 第一次进入允许落盘的多轮任务时建立；每次用户明确提出变化就合并到当前有效状态，无需再问一次确认。被替代的旧值不再并列生效。区分用户决定、助手建议和未解决项，建议不能自动变成确认。
- 先读状态再写新 Prompt。已有 `route_id` 时沿用，不因新反馈里的材质、颜色或“质感”词重新路由。
- 参考图变更只改对应 `@图N` 行和受影响描述；保留仍有效的目标、比例、排版、结构和授权。
- 最终 Prompt 必须把状态中的有效决定展开成独立正文，不能把状态文件路径、聊天历史或“上一版”交给生成模型。
- 执行范围不是永久授权；恢复时核对已完成的提交和剩余范围，不因状态写着已授权而重抽、重试或增加数量。
- 任务完成后保留状态文件，标记最终结果和确认状态；不要删除原始候选或覆盖原始素材。

## 恢复边界

如果恢复时没有明确的任务目录或状态文件，不能猜测最近文件夹、最近修改的图片或上一条 Prompt。能从当前输入继续的就按当前输入处理；会改变目标、参考职责或执行授权时，只询问缺失项。

当前加载钩子只加载项目基础设定，不承诺自动恢复任务。状态文件的准确路径由本任务上下文或用户指定；恢复后按明确路径读取，不扫描其他任务，不自动升级项目钩子。缺少宿主可靠的会话到任务映射前，不加全局当前任务指针。
