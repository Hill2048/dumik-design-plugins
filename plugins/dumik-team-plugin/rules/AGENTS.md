## 二、全案不可破底线

1. **纯无字底图 + 三层参考隔离 + 场景配色与光学材质底线**：除产品本体原生丝印/刻字或用户明确指定画内结构字（标 `[画内字白名单]`）外，严禁标题、卖点字、标尺、引线、圆框；带水印/UI 的 `素材/飞书画布/` 截图仅作写词前看图用，**严禁喂入 API，也严禁照抄竞品图的“光秃白墙+孤桌单杯”棚拍感**；`制作/` 下的未定稿候选图属 L3 禁用区严禁垫图，说「不要垫图」只清 L3/L2，**绝不误删 L1（白底图、人物/场景身份卡与已定稿母版）**，发包前去重；**所有实景生活与功能动作屏须保底全案配色结构（亮区+暖桥+深色锚点+主角），需要稳住光影与风格时正常垫入 `设定集/场景身份卡/` 核心场景母版（防风格失稳），但显式清掉并更换原图摆件，每屏按动线配 ≤3 件新鲜不重样生活搭配**，**凡出现任何人物（含仅露手/腕/袖/肩背特写）必须无例外垫入人物身份卡**；金属结晶类产品必保高反差不规则冶金晶粒金属体量（防发粉发灰喷砂与具象星形雪花纹，失真必标缺陷走 `即梦 5.5` 修）；透明容器/实验缸/护盾严禁普通玻璃青绿切边（统一写无铁纯无色光学石英水晶），**对比实测须控制变量（同饮品/同介质，且热升热气 vs 无热气、保冰大方冰+冷气+干壁 vs 极小小碎冰+化水变淡+满壁水珠、防锈左清右浊、拼色底座无缝坐实）**；塑胶/烤漆等部件须按实物真实光泽度写词（忌直写「PP/塑料」出灰暗廉价感，哑光实物禁乱加「骨瓷/高光」防过冲油光）。
2. **零本地运行垃圾 + 全流程中文命名 + 防压缩图定稿**：项目内禁止落盘 `.json` 队列、`拆解清单.md`、`.pytest_cache` 或 `运行记录`；**全流程所有候选图、导出图、修复图、联系表与文件夹名称必须使用中文**（仅保留标准编号 `MS/S/M/E` 与扩展名，如 `候选_01.png`、`<原名>_已修复.png`、`<原名>_已修复.psd`，严禁 `s01_float_1.png`、`candidate`、`_repaired` 等英文命名或英文后缀）；**严禁把聊天框上传附件（`.user_uploaded/`，客户端会自动压为 1024px 有损图）或长边 `< 1500px` 的图直接当定稿母版归档或删原 2K 候选**，必须先向用户索要本机无损原图路径；生图结束立刻 `--status` 同步 `project.md` 并清理 `%TEMP%\dumik-runs\`。
3. **授权、字体与汇报**：未收到用户本轮明确下令「开始生图 / 出图 / 生成 / 跑图」前绝不调付费接口；**全插件所有 HTML 报告、工具面板与脚本标注统一字体规范：英文与数字用 `Google Sans`（`Google Sans Flex`），中文用 `MiSans`（`MiSans VF`）**；列举任何编号必须写成 **`编号 4~6字卖点`**（如 `S01 健康对比`），极简中文人话，不自建 PR/分支。

## 三、插件发版与公告规则

- **仅在用户明确下令时才推送与发版**：日常修改插件代码、Skill 或脚本后只在本地保存并完成测试，**严禁私自 `git push` 或发行 GitHub Release**；只有用户本轮明确说「推送 / 发布 / 发版」时，才递增版本号（默认 `+0.0.1`）同步更新 `.codex-plugin/plugin.json`、`plugin.json`、`assets/skill-versions.json`，并运行 `scripts/release_dumik_plugin.ps1 -NotesFile "<公告>"` 发新 GitHub Release。
- 公告必须基于 `git log <上个tag>..HEAD` 汇总**全部**实际变化，**禁止写 `# DUMIK Team Plugin v...` 重复一级标题**，按 `✨ 新功能 / ⚡ 优化与改进 / 🐛 问题修复` 列 `- **加粗人话小标题**：一两句讲清变化`，末尾附 `compare/<上个tag>...v<新版本>` 链接。
